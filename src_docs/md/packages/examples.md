# Examples

Python and PythonQt examples for FontLab 9 live in their own repository and site,
not in this documentation:

- Site: <https://code.fontlab.com/fontlab-python-examples/>
- Source: <https://github.com/fontlabcom/fontlab-python-examples>

Like [Scriptmix](scriptmix.md), it is a script collection, not a runtime package.
Install `fontlab-fly` and `fontlab-fontlabapp` first; see
[Install into FontLab](index.md#install-into-fontlab).
