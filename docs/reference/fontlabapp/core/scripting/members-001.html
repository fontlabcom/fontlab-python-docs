    font_id 

    font_id(package: Any) -> int

    Return the font_id that FontLab's fontpr tools need for package.

    What: int(package.fgId), the FontGate id of the package. Why: fontpr finds a font by its FontGate id (MCPTools::findPackage -> flWorkspace::findPackageId compares fgId, source mcptools.cpp:1025-1035, flworkspace.cpp:1278-1287), and get_fonts reports that id. package.id is a different id (the flObject id). With package.id a tool fails with "Font id not found", or, when the ids collide, reads or writes ANOTHER open font. Use: fontpr.call("get_font_info", font_id=scripting.font_id(package)). Keep package.id for current_package(expected_id) and the other identity guards; those compare flPackage.id.
