    fontlabapp.fontui

    fontui

    Qt controls for FontLab objects and FontParts-style fonts. Qt loads only at construction.

    What it holds: the general browsers, previews, features editor and Designspace panel, the Qt lifetime base (lifecycle), the pure models, the sequence canvas, and the editors for FontParts-style fonts: font info, groups, kerning, transform, batch and glyph sequence. fontlabapp.fontui.feature_blocks reads and writes exact VFJ feature source through Fontport.

    Lazy by design: this module imports no editor module and no PythonQt. A factory imports its module only when you call it, which keeps the FontLab 5 s cold-import limit.

    Fontport: the FontParts editors validate and apply data with fontlab_fontport. That package depends on this one, so it is an optional extra: pip install "fontlab-fontlabapp[fontport]". Without it, calling one of those factories raises ImportError that names the extra. Everything else here works without Fontport.

    Moved back (issue 201): fontlab_fontport.ui held these editors for one release. Fontport now has no UI; its ui package only raises ImportError. old: from fontlab_fontport.ui import kerning_editor new: from fly.ap.fontui import kerning_editor
