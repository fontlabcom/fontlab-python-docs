    fontlabapp.anchors.writer

    writer

    Shared plan and write kernel of the anchor writer scripts.

    What: the Anchors scripts (Rename Bulk, Center Horizontally, Place From Bounds, Snap To Metrics, Round To Grid, Delete By Name, Mirror Across Masters) share one model. A script planner turns one layer into Change rows. Each row can hold one Edit:

    • ("set", name, (x, y)): move the anchor; add it when it is missing;
    • ("remove", name, None): delete every anchor with this name;
    • ("rename", name, new): rename every anchor with this name.

    collect runs the planner on every editable layer and returns a Plan. require_safe refuses the whole batch before any history exists. apply_work writes all edits as ONE native Undo step and reads every value back.

    How: apply_work builds every native pin and point first (prepare), then calls fontlabapp.core.history.glyphs.commit with operation="geometry". The commit discloses queued native updates and refuses auto layers in the edit list, glyphs that own an auto layer and bases of auto composites (also through other composites). Then it inits history, runs write, stamps the glyphs, sends one notification and stamps again. unstored is the read-back: a value that FontLab did not keep raises RuntimeError. A failure after history started raises history.PartialWriteError ("... use Edit > Undo").

    Why: FontLab cannot Redo an existing anchor moved to 0, 0 (FontLab issue 8527), so require_safe refuses that move. A new pin gets its name-derived appearance now (anchor_copy.APPEARANCE), because FontLab infers it only on Redo or reopen. An existing pin keeps its own style and expressions: write edits the existing pin object in place.

    This module imports only the standard library and stdlib-only App modules at load time. PythonQt, FontLab and anchor_copy load inside the functions, so FontLab's 5-second cold import stays fast. The panel base is in fontlabapp.anchors.panel.model. Offline tests do not prove native Undo/Redo.

    How to use (a script)::

    import fly.ap.anchors.panel.model as anchor_panel
import fly.ap.anchors.writer as anchor_writer

def planner(glyph, master, layer):
    return [anchor_writer.Change("top", "1, 2", "0, 2", ("set", "top", (0, 2)))]

class Panel(anchor_panel.panel_type()):
    TITLE, KEY = "Example", "anchors_example"

    def planner(self):
        return planner
