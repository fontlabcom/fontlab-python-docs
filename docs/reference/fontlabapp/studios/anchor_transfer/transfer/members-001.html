    apply 

    apply(tool: Any, action: str, dry: Dry, replan: Callable[[], Dry | None], *, allow_bases: bool = False) -> bool

    Write exactly the edits of dry as one named Undo step.

    replan builds the same plan from the live font; when it differs from dry (another edit, another source or file) Apply raises ValueError(STALE) before any write. Return True when FontLab committed; a refusal leaves the shell's status text and returns False.

    dry_run 

    dry_run(glyphs: list[Any], masters: list[str], planner: Callable[..., list[Any]], facts: Any) -> Dry

    Plan once with anchors.writer.collect and decide whether Apply may run.

    Auto layers are listed as skipped; a glyph that owns auto layers is refused; a base of auto glyphs needs the "Edit bases" tick (bases); an existing anchor moved to 0, 0 and repeated anchor names are refused by anchors.writer.require_safe (without its auto policy, which is above).
