    fontlabapp.studios.font_audit.model

    model

    Font Audit calculations over one _records.Catalogue: the absorbed reports' rules.

    What: the Font Overview cards, the Label Statistics groups, the Glyph Table CSV rows and file format, the Unicode Coverage blocks, the Empty Glyphs scan and the shared texts of each report, kept exactly as in the Scriptmix originals (thresholds, defaults, order, formats). Overview "Empty" means no contours and no components on the current master; Empty Glyphs counts contours only, on every master (a missing layer is empty): the originals differ and so do these helpers. Pure and Qt-free. Used by fontlabapp.studios.font_audit (session and tabs).
