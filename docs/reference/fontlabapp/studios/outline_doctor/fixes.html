    fontlabapp.studios.outline_doctor.fixes

    fixes

    Outline Doctor fixes: planners, native writers and read-back checks.

    What: the eleven Scriptmix outline fixers, ported with their thresholds, options, row texts and checks: Delete Small/Duplicate Contours, Add Extremes, Fix Zero Handles, Delete Close Points, Straighten Short Curves, Curve All Straights, Straighten All Curves, Retract Handles, Round Coordinates and Remove Overlap. Every planner reads only; write_* runs inside the session's single history step; verify_* returns mismatch texts. Why: checks.CHECKS registers each trio so one session drives them all. Each planner also returns the after-geometry the TGlyph ghost draws.
