    app_shell 

    app_shell(title: str, preview: str | None = None, tabs: Any = (), parent: Any = None, *, package: Callable[[], Any] | None = None) -> Any

    Return an owned studio window shell: preview pane, tabs and status line.

    preview is "tglyph", "tmetrics" or None; tabs are fontlabapp.studios.TabSpec values. show() sizes it to about 80% by 75% of the screen. Writes go through history(label, glyphs, mutate, layers=...).

    batch_panel 

    batch_panel(recipe: Callable[[], Any], parent: Any = None, on_finish: Callable[[list], None] | None = None, python: str | None = None) -> Any

    Run recipe() over source UFOs in a child Python; on_finish(results).

    The child is python= or, if that is None, $FONTLABAPP_BATCH_PYTHON. It must be Python 3.11+ with fontlab-fontport installed. With neither set, Start refuses to run and says so in the panel status.

    glyph_browser 

    glyph_browser(font: Any, parent: Any = None, on_activate: Callable[..., object] | None = None, multiple: bool = False) -> Any

    Keep the handle alive, show handle.widget, call refresh() after external edits and close() when done. on_activate runs for an activated glyph; multiple allows a multi-selection.

    kerning_snapshot 

    kerning_snapshot(package: Any, *, typed: bool = False) -> Any

    Read every master's kerning pairs and classes of a live native package.

    Returns a KerningSnapshot (masters, pairs, groups) to pass back as expected= to write_kerning; reading changes nothing. With typed=True pair sides are (name, "glyphMode" | "groupMode"), so a group and a glyph of the same name stay distinct; the default keys use the legacy "@name" strings for groups.

    remove_hints 

    remove_hints(layer: Any, label: str, *, glyph: Any, commit: Callable[..., Any] | None = None) -> Any

    glyph owns layer; commit(label, layers, glyphs, mutate, read_back) runs the history step (AppShell.history in studios). Returns the HintState after the write; a layer without PostScript hints is untouched.

    transform_editor 

    transform_editor(font: Any, name: str | None = None, parent: Any = None, on_change: Callable[[Any, Any], None] | None = None, on_invalidate: Callable[[], None] | None = None) -> Any

    Preview an affine transform of one detached UFO glyph.

    on_change(recipe, result) follows each good preview. The source font is never changed. Keep the handle and call close() when done. on_invalidate() clears linked proof before subsequent attempts; it is registered after the initial preview and must not calculate or publish.

    write_kerning 

    write_kerning(package: Any, edits: Any, undo_name: str, *, expected: Any = None) -> bool

    Write {master: {pair: value or None}} on any masters as one named Undo step.

    Only changed masters are range-checked; the result is read back. Raises ValueError for an unknown master, pair or out-of-range value and when expected is stale. Returns False when nothing changes.
