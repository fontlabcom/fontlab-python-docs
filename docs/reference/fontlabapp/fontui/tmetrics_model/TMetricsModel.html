    fontlabapp.fontui.tmetrics_model.TMetricsModel

    TMetricsModel dataclass

    Shaped text over font with rows, a visual selection and readouts.

    Complete member index

    Every captured member retains its own identity. Identical captured declaration text is linked once; this does not establish native inheritance or interchangeable objects.

    cells attribute tuple[Cell, ...]

    font attribute Any (shared captured text)
    geometry function (self, viewport_width: float=0.0) -> Geometry Map cells to pixels for a canvas at least <code>viewport&#95;width</code> wide.

    layer attribute str | None (shared captured text)

    outline_of function (self, font: Any, name: str) -> Any <code>outline(font, name)</code>, built once per scope; failures are not remembered.
    outline_scope function (self, kept: dict[Any, Any] | None=None) -> Iterator[None] Share one outline per glyph across every read inside the block (one refresh).

    selected attribute int | None
    selected_cell function (self) -> Cell | None Return the selected cell, or None.
    set_wrap_width function (self, width: float | None) -> bool Set the row width in font units; return True when the rows changed.
    settings attribute Settings
    source attribute (self) -> Any The glyph set read for metrics and outlines: <code>font.getLayer(layer)</code>, else the font.
    status attribute str
