    apply_cuts_to_layer 

    apply_cuts_to_layer(result, source_contours, target_contours, overlap=0)

    Apply cuts from an analyzed layer to a compatible target layer.

    Uses the parametric locations (contour_idx, node_idx, t) stored in each CutPair to evaluate new coordinates on the target contours, then splits at those coordinates. No MAT recomputation is needed.

    Args: result: StrokeSepResult from analyzing source_contours source_contours: list[Contour] -- the contours that were analyzed target_contours: list[Contour] -- compatible contours from another master overlap: float -- extension past cut boundaries (font units, default 0)

    Returns: list[Contour] -- target contours with cuts applied (new objects, target_contours are not modified)

    Raises: ValueError: if target_contours are not structurally compatible

    Returns: True if compatible

    insert_cut_nodes 

    insert_cut_nodes(plan, contours, reference=None)

    Insert the planned cut nodes into clones of contours.

    Per segment the inserts run in descending t, so the left part keeps a reparametrised t' = t / t_prev; segments run in descending ordinal so earlier ordinals stay valid. The original start node is kept.

    Args: plan: from plan_cut_nodes (reference master) contours: list[Contour] -- this master's contours reference: list[Contour] -- the reference contours; when given, an inserted endpoint keeps the reference cut direction on this master (see _solve_master_ts); else it keeps the reference t.

    Returns: (new_contours, cuts): cloned contours with the nodes inserted, and the plan's cuts as ((x, y), (x, y)) pairs at those exact nodes.

    Raises: ValueError on quadratic (TrueType) contours.

    plan_cut_nodes 

    plan_cut_nodes(cut_pairs, contours, snap=1.0)

    Decide on the reference contours how each cut endpoint becomes a node.

    An endpoint closer than snap units (or _T_EPS in t) to a segment end reuses that on-curve node; otherwise a node is inserted at t. Ordinals count on-curve nodes only, so the plan does not depend on where a contour starts (Glyphs keeps the start node last).

    Args: cut_pairs: list[CutPair] -- from StrokeSep.analyze (reference master) contours: list[Contour] -- the analysed reference contours snap: float -- reuse-node distance on the reference master

    Returns: list of ((ci, on_idx, t), (ci, on_idx, t)); t == 0 means the existing on-curve node #on_idx. Degenerate cuts (both ends one node) are dropped.
