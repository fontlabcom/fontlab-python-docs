    npa_align 

    npa_align(glyph, scope_layers, NodeActions, mode, smart_shift=True, keep_relations=False, lerp_shift=False, intercept=False, extrapolate=False, use_target=False)

    Align selected nodes using the given mode string.

    Modifier kwargs are forwarded to NodeActions.nodes_align. When use_target=True, each layer's stored align target (set via npa_target_set) is passed in as the override target; layers without a stored target fall back to the mode-computed one.

    npa_align_to_y 

    npa_align_to_y(glyph, scope_layers, NodeActions, y_by_layer, smart_shift=True, keep_relations=False, lerp_shift=False, intercept=False, extrapolate=False)

    Align selected nodes vertically to a per-layer Y value.

    y_by_layer: dict[layer_name -> y]. The host fills it from each layer's master metrics (ascender, cap height, x-height, baseline, descender). Layers missing from the dict are skipped. Modifier kwargs as npa_align.

    npa_contour_align 

    npa_contour_align(glyph, scope_layers, NodeActions, ContourActions, align_x='C', align_y='E', mode='CC', contours_A_by_layer=None, contours_B_by_layer=None)

    Align selected contours to each other or to a target.

    Args: align_x (str): Horizontal alignment: 'L', 'R', 'C', 'K' (keep). align_y (str): Vertical alignment: 'B', 'T', 'E', 'X' (keep). mode (str): One of: 'CC' - selected contours to each other. 'CL' - selected contours to the layer bounding box. 'CN' - selected contours to a selected on-curve node; the first selected contour hosts the target node. 'AB' - group A to group B; pass contours_A_by_layer and contours_B_by_layer as {layer_name: [contour, ...]}. contours_A_by_layer (dict|None): per-layer group A snapshots. contours_B_by_layer (dict|None): per-layer group B snapshots.

    When contours_A/B are None, uses module-level _contour_group_A/B.

    npa_contour_bool 

    npa_contour_bool(glyph, scope_layers, operation='add', reverse=False)

    Boolean operation on selected contours (all if none) - FL contour_bool.

    The operands are read ONCE on a reference layer (the active layer if in scope, else the first) and applied by contour index to every layer in scope: Glyphs keeps a separate selection per layer, so other masters have none to read. Left fold in index order (reverse: from the last, FL Alt); the result takes the place of the base operand. Open contours are not operands and stay. Layers whose contour count differs from the reference are skipped and reported; results that differ in node structure across layers are reported (no fix).

    The geometry is the host's: each layer must offer path_boolean(indices, operation, reverse) -> (status, new_paths, message) (Glyphs: trLayer.path_boolean, engine proxy/gs3/objects/pathops).

    Args: operation (str): 'add', 'subtract', 'intersect' or 'exclude'. reverse (bool): fold from the last operand.

    Returns: dict: layer name -> status ('OK', 'EMPTY', 'TOO_FEW', 'BAD_INDEX', 'ENGINE_ERROR', 'INCOMPATIBLE', 'NO_HOST'). Empty if nothing ran.

    npa_contour_order 

    npa_contour_order(glyph, scope_layers, NodeActions, ContourActions, direction=0, mode='BL', reverse=False)

    Sort contour order within each shape.

    Args: direction (int): Axis selector — 0 = sort by X, 1 = sort by Y. mode (str): Reference corner: 'BL', 'TL', 'BR', 'TR'. reverse (bool): Descending on the primary axis. Ties still read left -> right / top -> bottom (a full list flip would break that).

    The order is computed ONCE on a reference layer (the active layer if in scope, else the first) and applied to every compatible layer, so masters cannot drift apart when contours are nearly level. Incompatible layers are sorted on their own and reported.

    npa_curve_optimize(glyph, scope_layers, NodeActions, CurveActions, method='tunni', curvature=(1.0, 1.0), proportion=(0.3, 0.3), select_one_node=False)
