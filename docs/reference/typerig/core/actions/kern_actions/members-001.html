    import_plan 

    import_plan(kset, master, flat, options=None, coverage=None, keys=None)

    Plan writing flat external kerning into a master, on the font's groups.

    Args: kset (KernSet) : the font's kerning (groups are read only) master (str) : target master flat (dict) : {(glyph, glyph): value}, names already mapped to the font options (dict) : see IMPORT_DEFAULTS coverage (iter) : glyphs the source knows (AFM CharMetrics); default: glyphs in flat keys (dict) : optional key glyphs per group, see kern_reclass.reclass

    Returns: (ChangeSet, report) - report: {'table', 'reclass', 'locked', 'flat', 'coverage', 'options'}

    interpolate_plan 

    interpolate_plan(kset, a, b, t, dst, pairs=None, mode='overwrite', base=None)

    dst = a + (b - a) * t per pair (t 0 = a, 1 = b, outside: extrapolate). A pair missing in a or b counts as 0 there, as Glyphs interpolates. base: pending changes that count as current.

    read_source 

    read_source(path)

    Read an import source file. AFM: KPX / KP pairs, CharMetrics as coverage. KRN: KPX lines that carry a value (a job list without values gives nothing). OTF / TTF: the GPOS kern feature flattened (fileio/otkern), every glyph as coverage. UFO (folder): kerning flattened through its own groups, every glyph as coverage. Returns {'path', 'name', 'font_name', 'kerning': {(a, b): value}, 'glyphs': [names] or None}.
