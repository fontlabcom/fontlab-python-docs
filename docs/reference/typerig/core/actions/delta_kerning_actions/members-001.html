    kern_target 

    kern_target(axes, tables, sides, groups, bases=None, fallback=None, group_rule=GROUP_RULE_DEFAULT, side_rule=SIDE_RULE_DEFAULT, extrapolate=True)

    Kerning of one target layer.

    axes: {axis name: [{'name', 'vstem'}]} the inputs of every axis used; tables: {input layer name: {(left, right): value}}; sides: {glyph: spot} baked in this target (Kern on); groups: {LEFT: {name: [glyphs]}, RIGHT: {name: [glyphs]}}; bases: {composite: base glyph} for exceptions; fallback: spot of the target's first row (factor 1), for pairs with no baked side under the complete rule.

    Every pair of any input is computed or reported. Returns {'pairs': {(l, r): value}, # to write (rounded) 'remove': [(l, r)], # skip rule: pairs with an unprocessed side 'keep': [(l, r)], # keep rule: the target's own value stays 'refused': {'@group': n pairs}, # group rule refuse 'counts': {'scaled', 'completed', 'skipped', 'kept', 'refused'}}

    side_factor 

    side_factor(row, solved=None, scales=None)

    Width factor of a glyph baked on a resolved target row (1. = 100 %): the row's Met. W when set (spacing follows it), else the scale solved on the group's reference glyph, else the glyph's own solved scale (units row, core bake entry 'scales'), else the row's width percent.

    side_spots 

    side_spots(key, side, groups, sides, bases=None, rule=GROUP_RULE_DEFAULT)

    Baked spots of one pair side. key: '@group' or a glyph; side: LEFT (groups[LEFT]: the glyphs' right-side groups) or RIGHT. sides: {glyph: spot} of the glyphs baked in this target with Kern on. bases: {glyph: first component} — an exception on a composite uses its base glyph. Returns a list of spots, [] (no baked glyph: unprocessed) or _REFUSED.

    write_plan(existing, result)

    What to change in a master's kerning: (set {pair: value}, remove [pair]). existing: {pair: value} of the master now. Pairs to keep and pairs no input has are left alone; equal values are not rewritten.
