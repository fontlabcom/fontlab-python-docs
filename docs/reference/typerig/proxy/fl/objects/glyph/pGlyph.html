    pGlyph

    Proxy to flGlyph and fgGlyph combined into single entity.

    Constructor: pGlyph() : default represents the current glyph and current font pGlyph(flGlyph) pGlyph(fgFont, fgGlyph)

    Methods:

    Attributes: .parent (fgFont) .fg (fgGlyph) .fl (flGlyph) ...
