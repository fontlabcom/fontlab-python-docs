    Supplemental documentation: Low-level FontLab font data API. fgFont provides glyphs, naming data, features and kerning; fgGlyph provides glyph data. Feature data is exposed by fgFont.features; there is no captured module-level fgFeatures class.

    Documentation is derived from captured and enriched Echopy source. Native objects are supplied by FontLab.
