    PythonQt.Qt.QPdfWriter

    QPdfWriter

    PythonQtInstanceWrapper object

    Native bases: PythonQtInstanceWrapper

    Supplemental documentation: Qt 5 reference:

    Detailed Description

    QPdfWriter generates PDF out of a series of drawing commands using QPainter. The newPage() method can be used to create several pages.

    Source: https://doc.qt.io/archives/qt-5.15/qpdfwriter.html
