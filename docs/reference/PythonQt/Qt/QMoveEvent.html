    PythonQt.Qt.QMoveEvent

    QMoveEvent

    PythonQtInstanceWrapper object

    Native bases: PythonQtInstanceWrapper

    Supplemental documentation: Qt 5 reference:

    Detailed Description

    Move events are sent to widgets that have been moved to a new position relative to their parent.

    The event handler QWidget::moveEvent() receives move events.

    Source: https://doc.qt.io/archives/qt-5.15/qmoveevent.html
