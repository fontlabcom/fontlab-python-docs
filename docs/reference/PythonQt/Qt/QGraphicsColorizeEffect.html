    PythonQt.Qt.QGraphicsColorizeEffect

    QGraphicsColorizeEffect

    PythonQtInstanceWrapper object

    Native bases: PythonQtInstanceWrapper

    Supplemental documentation: Qt 5 reference:

    Detailed Description

    A colorize effect renders the source with a tint of its color(). The color can be modified using the setColor() function.

    By default, the color is light blue (QColor(0, 0, 192)).

    Source: https://doc.qt.io/archives/qt-5.15/qgraphicscolorizeeffect.html
