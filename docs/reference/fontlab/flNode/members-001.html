    angle: Any

    angle

    applyTransform(QTransform)

    canBeHobby() -> bool

    bool canBeHobby()

    Source: FontLab Proteus API documentation

    canBeSmooth 

    canBeSmooth() -> bool

    bool canBeSmooth()

    Returns True if the handles around this node are already collinear (pointing in opposite directions through the node), meaning it could be set to smooth without changing the curve's shape.

    Source: FontLab Proteus API documentation

    canCollapse 

    canCollapse() -> bool

    bool canCollapse()

    Returns True if this node's handles are short enough (effectively zero-length) that they can be safely collapsed without changing the visual appearance of the outline.

    Source: FontLab Proteus API documentation

    canImprove 

    canImprove() -> bool

    bool canImprove()

    Returns True if FontLab's curve-quality heuristics think this node's position or handle angles could be improved for better curve tension.

    checkVectors() -> bool

    bool checkVectors()

    Examines the handles around this node to see if they are well-formed — for example, that they don't have zero length or degenerate positions. Returns True if everything is in order.

    Source: FontLab Proteus API documentation

    cloneMapped(arg0: QTransform) -> flNode

    flNode cloneMapped(QTransform)

    Creates a copy of this node with its coordinates transformed by the given matrix. The original is not modified. Useful for building reflected or rotated copies of individual points.

    Source: FontLab Proteus API documentation

    collapseHandles 

    collapseHandles() -> bool

    bool collapseHandles()

    If the off-curve handles of this node are sitting on top of their on-curve anchor (zero length), this method removes them and converts the segment to a line. Returns True if handles were collapsed.

    Source: FontLab Proteus API documentation

    convertToCurve 

    convertToCurve(smooth: Any = ...) -> bool

    bool convertToCurve([bool smooth = false])

    Similar to convertToCurves but targets just the single outgoing segment. Pass smooth=True to also set the smooth flag on the resulting node. Returns True on success.

    Source: FontLab Proteus API documentation

    convertToCurves 

    convertToCurves() -> bool

    bool convertToCurves()

    Converts this on-curve node and its neighboring segments to use cubic Bézier control points, turning what may have been straight lines into curve segments ready for handle manipulation. Returns True if the conversion was performed.

    Source: FontLab Proteus API documentation

    convertToLine 

    convertToLine() -> bool

    bool convertToLine()

    Removes the off-curve handles from the segment leading into this node, making it a straight line segment. Useful for simplifying curves to line segments in bulk cleanup scripts. Returns True on success.

    Source: FontLab Proteus API documentation

    copyFrom(withSelected: Any = ...) -> Any

    copyFrom(Node[, withSelected=False])

    Copies the position, type, smooth flag, and other properties from another node into this one. Pass withSelected=True to also copy the selection state.

    getLines 

    getLines(*args: Any, **kwargs: Any) -> Any

    (QLineF, QLineF)/None getLines()

    Returns the two tangent lines passing through this node — one toward the previous segment and one toward the next. This is useful for smooth-node validation or for computing intersection points. Returns a tuple (QLineF, QLineF), or None if the node has no handles.

    Source: FontLab Proteus API documentation

    Source: FontLab Proteus API documentation

    Returns True if this node is a corner — meaning the angle between its incoming and outgoing tangents exceeds angle degrees. The default threshold of 10° filters out nearly-smooth nodes that only deviate slightly.

    Source: FontLab Proteus API documentation

    isCurve 

    isCurve() -> bool

    Returns True if this node is an on-curve node that is part of a curve segment (as opposed to a line segment).

    Returns True if this node has the same coordinates as another node (within tolerance). The optional offset shifts one node before comparison — useful for checking compatibility between masters that have different side-bearings.

    Returns True if this node sits at a local extremum of the outline. Set x=True to check horizontal extremes (leftmost/rightmost), x=False for vertical. The open flag controls whether open contour endpoints count, and limit sets a flatness tolerance.

    Source: FontLab Proteus API documentation
