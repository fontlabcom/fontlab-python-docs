    fontlab.flLayer

    flLayer

    In FontLab, a layer is the container inside a glyph that holds the actual drawing for one master. If your font has a Light master and a Bold master, then every glyph has (at least) two layers — one for each master. The layer is where shapes live, where metrics are set, and where anchors and guidelines for that specific master are stored.

    Inherits from flObject.

    What is a Layer?

    Think of layers as the per-master "slots" inside a glyph:

    font
 └── glyph "A"
      ├── layer "Light"    ← shapes, metrics, anchors for the Light master
      ├── layer "Regular"  ← shapes, metrics, anchors for the Regular master
      └── layer "Bold"     ← shapes, metrics, anchors for the Bold master
    Layer Types

    Not every layer is a master. FontLab supports several layer types, each with a different role:

    Layer type What it's for
    Master layer (isMasterLayer = True) The real drawing layers that correspond to design-space masters. These are the layers that participate in interpolation.
    Service layer (isService = True) Non-printing helper layers — for example a layer storing reference artwork or construction guides. They show up in the editor but don't export.
    Mask layer (isMaskLayer = True) A special overlay layer for each master used during manual hinting and for storing reference outlines. Accessible via getMaskLayer().
    Image layer (isImgLayer = True) A dedicated layer for raster image data attached to a glyph — typically a scan or reference image to draw on top of.
    Body layer (isBodyLayer = True) The primary drawing layer for a glyph in simple (non-variable) fonts.
    Auto layer (autoLayer = True) A layer whose content is generated automatically, usually by an interpolation recipe. You can read its content but manual edits may be overwritten.
    What Lives on a Layer

    A layer is not just outlines. It holds everything that can vary between masters:

    • Shapes — the contours and composite references that define the glyph drawing
    • Metrics — the advance width, left sidebearing (LSB), and right sidebearing (RSB)
    • Anchors — named attachment points used for mark positioning and component composition
    • Guidelines — per-glyph guidelines (as opposed to font-wide guidelines)
    • Stems and zones — PS hint stems and alignment zones for this master
    • TrueType hinting — the TTH command program for this master
    • A note — freeform text you can attach to this layer for editorial comments

    Tutorial: Set Width of All "A" Glyphs Across All Masters

    This script shows a real workflow: finding every glyph named "A" in the font, iterating over all its master layers, and setting a consistent advance width on each one.

    import fontlab as fl
from fontlab import flLayer

font = fl.CurrentFont()

TARGET_GLYPH = "A"
NEW_WIDTH     = 620   # desired advance width in font units

glyph = font[TARGET_GLYPH]
if glyph is None:
    print(f"Glyph '{TARGET_GLYPH}' not found")
else:
    for layer in glyph.layers:
        # Only touch master layers — skip mask, service, and image layers
        if not layer.isMasterLayer:
            continue

        old_width = layer.advanceWidth
        layer.advanceWidth = NEW_WIDTH

        print(
            f"  [{layer.name}]  "
            f"width {old_width:.0f} → {NEW_WIDTH}"
        )

    glyph.changed()

fl.Update()
print("Done.")

    Extending the same pattern to all glyphs in the font:

    import fontlab as fl

font = fl.CurrentFont()

# Set all capital letters to a consistent side-bearing on the Regular master
REGULAR_MASTER = "Regular"
TARGET_LSB     = 70

for glyph in font.glyphs:
    if not glyph.name[0].isupper():
        continue

    for layer in glyph.layers:
        if layer.name != REGULAR_MASTER:
            continue
        if not layer.isMasterLayer:
            continue

        # Clear any expression so we can set a numeric value
        # Set a numeric LSB via the metrics expression string
        layer.resetMetricsLeft()
        layer.metricsLeft = str(TARGET_LSB)
        glyph.changed()

fl.Update()
print(f"Set LSB={TARGET_LSB} on all uppercase glyphs in '{REGULAR_MASTER}'.")

    Common Patterns

    Iterate only master layers

    for layer in glyph.layers:
    if layer.isMasterLayer:
        print(f"{layer.name}: width={layer.advanceWidth}")

    Read metrics in all masters

    font  = fl.CurrentFont()
glyph = font["n"]

print(f"{'Master':<20} {'Width':>8} {'LSB':>8} {'RSB':>8}")
print("-" * 46)
for layer in glyph.layers:
    if layer.isMasterLayer:
        ib  = layer.inkBox()
        lsb = ib.x()
        rsb = layer.advanceWidth - (ib.x() + ib.width())
        print(f"{layer.name:<20} {layer.advanceWidth:>8.1f} {lsb:>8.1f} {rsb:>8.1f}")

    Set a metrics expression (link LSB to another glyph)

    # Link the 'n' glyph's LSB to the 'H' glyph on all master layers
for layer in font['n'].layers:
    if layer.isMasterLayer:
        layer.metricsLeft = "=H"
font['n'].changed()
fl.Update()

    Add an anchor to all master layers

    from PythonQt.QtCore import QPointF
from fontlab import flPinPoint
import fontlab as fl

font  = fl.CurrentFont()
glyph = font["a"]

for layer in glyph.layers:
    if not layer.isMasterLayer:
        continue
    # Remove existing "top" anchor if present, then add a new one
    existing = layer.findAnchor("top")
    if existing:
        layer.removeAnchor(existing)
    # Position the anchor at the bounding-box top center
    bb = layer.inkBox()
    x  = bb.x() + bb.width() / 2
    y  = bb.y() + bb.height()
    layer.createAnchor("top", QPointF(x, y), 0)

glyph.changed()
fl.Update()

    Check interpolation compatibility across all masters

    font   = fl.CurrentFont()
glyph  = font["g"]
layers = [l for l in glyph.layers if l.isMasterLayer]

reference = layers[0]
for layer in layers[1:]:
    ok = reference.isCompatible(layer, strong=True)
    status = "OK" if ok else "INCOMPATIBLE"
    print(f"  {reference.name} ↔ {layer.name}: {status}")

    Leave an editorial note on a layer

    for layer in glyph.layers:
    if layer.name == "Bold" and layer.isMasterLayer:
        layer.note = "Optical correction needed on right shoulder — see ticket #42"
        break

    Count total nodes across all master layers

    font  = fl.CurrentFont()
glyph = font["g"]

for layer in glyph.layers:
    if layer.isMasterLayer:
        n = layer.nodesCount()
        print(f"{layer.name}: {n} nodes")
