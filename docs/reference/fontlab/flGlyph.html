    fontlab.flGlyph

    flGlyph

    flGlyph representation

    Constructors: flGlyph() flGlyph(flGlyph) flGlyph(flObject) flGlyph(fgGlyph, fgFont)

    Native bases: object

    Supplemental documentation: A FontLab editing glyph containing flLayer objects. Read glyph.name and iterate glyph.layers to inspect layer names. Unicode assignments belong to the associated fontgate glyph; they are not flGlyph attributes.

    Example::

    glyph = fl.CurrentGlyph()
if glyph:
    print(glyph.name)
    for layer in glyph.layers:
        print(layer.name)
