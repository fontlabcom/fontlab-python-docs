    fontlab.flGlyphInfo

    flGlyphInfo

    Canvas proxy for a rendered glyph.

    What is flGlyphInfo?

    flGlyphInfo is the top-level entry point into the canvas info system. When a glyph is displayed in the metrics view or glyph editor, FontLab wraps it in an flGlyphInfo that knows everything about how it appears on screen: its bounding rectangle in pixels, its screen position, whether it is currently active for editing, and where all its shapes, contours, and nodes are.

    This is the class you reach for when writing interactive tools or canvas decorators. canvas.activeGlyphInfo() is the single most important call for tool code — it gives you the live rendering context for whatever glyph the user is currently editing.

    flGlyphInfo is the root of the canvas info hierarchy:

    flGlyphInfo              ← top-level proxy for one rendered glyph slot
  ├── flLayerInfo        ← canvas proxy for a layer (bounding rect)
  └── (via shapes/contours)
        flShapeInfo      ← shape-level: move, hit-test, composite queries
          └── flContourInfo  ← per-contour: node list, parametric hover point
                └── flNodeInfo  ← per-node: move in glyph space, repaint rect

    The base info classes (flSearchInfo, flGraphicsInfo) hold shared infrastructure — distance values and canvas transform matrices — and are described in their own files.

    When do you use it?

    canvas.activeGlyphInfo() is the single most useful call for interactive tool code. It gives you the currently-being-edited glyph's canvas context — its screen position, bounds, and the full tree of shapes, contours, and nodes with canvas coordinates.

    Tutorial

    The standard flow in any canvas tool starts with getting the flGlyphInfo for the active glyph, then querying it for shapes, contours, or nodes near the mouse position.

    from PythonQt.QtCore import QPointF
import fontlab as fl

# ============================================================
# Step 1: Get the active glyph info from the canvas.
# This works in both the glyph editor and the metrics view.
# ============================================================

ws     = fl.flWorkspace.instance()
canvas = ws.getActiveCanvas()
if canvas is None:
    print("Open a glyph window first.")
    raise SystemExit

gi = canvas.activeGlyphInfo()
if gi is None:
    print("No glyph is currently active for editing.")
    raise SystemExit

print(f"Active glyph:      '{gi.name}'")
print(f"Is active:          {gi.isActive}")
print(f"Canvas bounds:      {gi.brectOnCanvas}")
print(f"Body rect (UPM):    {gi.bodyRectOnCanvas}")
print(f"Null glyph:         {gi.isNullGlyph}")

# ============================================================
# Step 2: Hit-test — did the user click inside the glyph?
# This is the fastest way to answer "is this click on ink?"
# ============================================================

mouse_pos = QPointF(250, 400)   # canvas-space click position
hit = gi.hitToShape(mouse_pos)
print(f"\nPoint ({mouse_pos.x():.0f}, {mouse_pos.y():.0f}) inside glyph: {hit}")

# ============================================================
# Step 3: Find the nearest shape to a mouse position.
# ============================================================

top_shape = gi.getTopHitShape(mouse_pos)
if top_shape:
    print(f"Top hit shape canvas bounds: {top_shape.brectOnCanvas()}")

# ============================================================
# Step 4: Find nearby contours (the magnetic snap pattern).
# This is how knife tools and add-node tools find the curve
# to snap to.
# ============================================================

nearby = gi.getNearbyContours(mouse_pos, 30.0, "")
if nearby:
    nearest = min(nearby, key=lambda c: c.dist)
    print(f"\nNearest contour at {nearest.dist:.1f}px from mouse")
    print(f"  Parametric position (exT): {nearest.paramExT():.3f}")
    nodes = nearest.getNodesInfo()
    print(f"  Contour has {len(nodes)} node(s)")

# ============================================================
# Step 5: Access the model data through .glyph.
# ============================================================

glyph = gi.glyph
layer = glyph.layers[0]
print(f"\nGlyph '{glyph.name}' has {len(layer.shapes)} shape(s) "
      f"on layer '{layer.name}'")

    Common Scripting Patterns

    Check if a canvas point hits any glyph content
    from PythonQt.QtCore import QPointF
import fontlab as fl

ws = fl.flWorkspace.instance()
gi = ws.getActiveCanvas().activeGlyphInfo() if ws.getActiveCanvas() else None
if gi:
    click = QPointF(300, 400)
    if gi.hitToShape(click):
        print("Click hit glyph ink.")
    elif gi.brectOnCanvas.contains(click):
        print("Click is in the glyph box but not on ink.")
    else:
        print("Click is outside the glyph box entirely.")
    Get all selected nodes from the active glyph
    import fontlab as fl

ws = fl.flWorkspace.instance()
gi = ws.getActiveCanvas().activeGlyphInfo() if ws.getActiveCanvas() else None
if gi:
    selected = gi.selectedNodes()
    print(f"Selected nodes ({len(selected)}):")
    for ni in selected:
        pt = ni.getGlyphPoint(True)   # rounded to integers
        print(f"  type={ni.node.type}  ({pt.x():.0f}, {pt.y():.0f})")
    Read kerning offset for a glyph in the metrics view
    import fontlab as fl

ws     = fl.flWorkspace.instance()
canvas = ws.getActiveCanvas()
if canvas:
    gi = canvas.activeGlyphInfo()
    if gi:
        kern_offset = gi.kerningOffset(True)
        print(f"'{gi.name}' kerning offset: {kern_offset:.0f} units")
