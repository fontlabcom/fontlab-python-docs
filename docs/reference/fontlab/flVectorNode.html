    fontlab.flVectorNode

    flVectorNode

    Guideline-anchored nodes.

    What are vector nodes?

    A vector node (called a "vector point" in the FontLab UI) is a special node that is pinned to a guideline. When the guideline moves, the node moves with it — automatically, across all glyphs that reference that guideline. This is the mechanism behind FontLab's power guidelines: you draw a guideline, attach nodes from multiple glyphs to it, and moving the guideline moves all the attached nodes at once.

    This makes vector nodes a powerful tool for variable font design. If you define a guideline at the x-height and attach the top of your lowercase letters to it, raising the x-height guideline automatically raises every attached node in every glyph.

    flAbstractVectorNode is the base class (provides the interface); flVectorNode is the concrete implementation you create and use in scripts.

    Static Methods (flVectorNode)

    Signature Description
    flVectorNode createInstance() Creates a detached flVectorNode ready to be attached to a guideline.
    bool isVectorNode(flObject) Returns True if the given object is an flVectorNode. Use this for type checking when iterating mixed node lists.

    Properties (flVectorNode)

    Name Type Access Description
    mode uint ro The current positioning mode of this vector node — absolute or relative tracking.
    guideline flGuideLine ro The guideline this node is attached to. Read this to find which guideline is driving the node's position.

    Tutorial

    Vector nodes are most useful in variable fonts where you want multiple glyphs to share a common alignment target. Here is how to check for and inspect existing vector nodes in a glyph.

    from PythonQt.QtCore import QPointF
import fontlab as fl
from fontlab import flVectorNode

# ============================================================
# Check whether any nodes in the active glyph are vector nodes
# (i.e. attached to guidelines).
# ============================================================

font  = fl.CurrentFont()
glyph = font['a']
layer = glyph.layers[0]

print(f"Checking '{glyph.name}' for vector nodes:")
found = 0
for shape in layer.shapes:
    for contour in shape.contours:
        for node in contour.nodes():
            if flVectorNode.isVectorNode(node):
                vn = node   # it IS an flVectorNode
                print(f"  Vector node at ({vn.x:.0f}, {vn.y:.0f})"
                      f"  attached to guideline: {vn.guideline}")
                found += 1

if found == 0:
    print("  No vector nodes found in this glyph.")

# ============================================================
# Create a vector node and attach it to a guideline.
# ============================================================

# First, find or create a guideline to attach to:
x_height_guide = next(
    (g for g in font.guidelines if g.expression == "=xHeight"), None
)

if x_height_guide:
    # Create a vector node at the x-height position:
    vn = flVectorNode.createInstance()
    vn.setPosition(QPointF(250, x_height_guide.centerPoint.y()))

    print(f"\nCreated vector node at ({250}, {x_height_guide.centerPoint.y():.0f})")
    print("Attach this node to a contour via contour.addVectorNode(vn).")
else:
    print("\nNo x-height expression guideline found.")
    print("Create one first: guide.expression = '=xHeight'")

    Common Scripting Patterns

    Count vector nodes across the entire font

    import fontlab as fl
from fontlab import flVectorNode

font = fl.CurrentFont()
total = 0
for glyph in font.glyphs:
    for layer in glyph.layers:
        for shape in layer.shapes:
            for contour in shape.contours:
                for node in contour.nodes():
                    if flVectorNode.isVectorNode(node):
                        total += 1

print(f"Total vector nodes in font: {total}")

    Find all guidelines that have attached vector nodes

    import fontlab as fl
from fontlab import flVectorNode

font = fl.CurrentFont()
used_guides = set()

for glyph in font.glyphs:
    for layer in glyph.layers:
        for shape in layer.shapes:
            for contour in shape.contours:
                for node in contour.nodes():
                    if flVectorNode.isVectorNode(node):
                        gl = node.guideline
                        if gl:
                            used_guides.add(id(gl))

print(f"{len(used_guides)} guideline(s) have attached vector nodes.")
