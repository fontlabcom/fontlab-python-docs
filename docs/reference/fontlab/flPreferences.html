    fontlab.flPreferences

    flPreferences

    flPreferences gives scripts read and write access to almost every setting in FontLab — the same settings you'd normally change in the Preferences dialog. You can read them to understand the current working environment, or write them to temporarily change FontLab's behavior for the duration of your script.

    You always access preferences through the singleton:

    from fontlab import flPreferences
prefs = flPreferences.instance()

    A word of caution: Changes to preferences take effect immediately and globally. If your script changes a preference, it stays changed even after the script finishes — the user's environment is affected. For settings you change temporarily, always save the original value and restore it when you're done:

    prefs = flPreferences.instance()

# Save original
old_snap = prefs.snapToGuidelines

# Change for your script
prefs.snapToGuidelines = False

# ... do your scripted work ...

# Restore original
prefs.snapToGuidelines = old_snap

    After changing any preferences, call flItems.notifyPreferencesChanged() so all panels and displays pick up the new values.

    Window-opening preferences

    Property Type Access Meaning
    generalActivateFontWindowOnOpen bool read/write Activate the Font window when opening a font; off by default.
    generalHideWarningDialogs bool read/write Suppress optional launch/opening dialogs; off by default. See behavior below.

    Active window when reopening a font

    generalActivateFontWindowOnOpen is a read/write boolean, off by default. When off, opening a font with saved windows returns to its saved active window. This also applies when saving glyph-window contents without panel/window layout. Older files use their saved selected tab when available, or preserve the window activated by the restoration order when no active-window information exists. Set it to True to activate the Font window instead:

    flPreferences.instance().generalActivateFontWindowOnOpen = True

    Window restoration must be enabled to restore a saved active window.

    Suppressing launch and font-opening dialogs

    generalHideWarningDialogs is a read/write boolean, off by default, corresponding to Preferences > General > Other > Hide warning dialogs:

    from fontlab import flPreferences
prefs = flPreferences.instance()
prefs.generalHideWarningDialogs = True

    The change takes effect immediately and is saved for subsequent launches. Set it to False to restore dialogs. It suppresses startup prompts (including crash reporting and Welcome), font-opening warnings, legacy note encoding conversion, and Important Font Note dialogs. Pending crash reports are sent automatically without dialogs; failed uploads are retained for retry. Autosaved fonts are moved to the Keep folder without reopening them. Automatic update checks are suspended while enabled; license restrictions still apply.

    Imports follow the configured rounding preference. Optional repairs (merging/renaming elements, renaming masters, removing linked width expressions) and encoding conversion are skipped. Required duplicate-glyph-name and cross-layer-reference repairs still run, with messages in Output. Font collections open all faces. Known damaged autosaves and Sketchboards are skipped without deletion. Opening errors are reported in Output instead of a dialog.

    For temporary use, save and restore the value with try/finally. MCP exposes the same setting as general.hide_warning_dialogs through get_preferences and set_preferences.

    Getting the Instance

    from fontlab import flPreferences
prefs = flPreferences.instance()
print(prefs.editorNodeSize)   # read a value
prefs.editorNodeSize = 8      # write a value

    Common Scripting Patterns

    from fontlab import flPreferences, flItems

prefs = flPreferences.instance()

# --- Read a value ---
print("Node size:", prefs.editorNodeSize)

# --- Change a value (always save the original first!) ---
orig = prefs.editorNodeSize
prefs.editorNodeSize = 8
# ... do your work ...
prefs.editorNodeSize = orig   # restore

# --- Notify the app after changes ---
flItems.notifyPreferencesChanged()

# --- Save/restore a full preferences snapshot ---
snapshot = prefs.save()
prefs.editorFillOpacity = 0   # make glyphs transparent
# ... do proofing work ...
prefs.load(snapshot)          # restore everything
flItems.notifyPreferencesChanged()

# --- Temporarily disable all snapping ---
snap_props = ['snapToGrid', 'snapToGuidelines', 'snapToOutline',
              'snapToBounds', 'snapToMetrics']
orig_snaps = {p: getattr(prefs, p) for p in snap_props}
for p in snap_props:
    setattr(prefs, p, False)
# ... do work without snapping ...
for p, v in orig_snaps.items():
    setattr(prefs, p, v)

    Tutorial

    from PythonQt.QtGui import QColor
import fontlab as fl
from fontlab import flPreferences, flItems

# ============================================================
# 1. Get the preferences singleton
# ============================================================

prefs = flPreferences.instance()
print("Preferences loaded. Dark mode:", prefs.isDark)
print("Data path:", prefs.dataPath)

# ============================================================
# 2. Reading preferences
# ============================================================
# These are just attribute reads — safe, no side effects.

print("\n--- Editor display ---")
print(f"  Node size: {prefs.editorNodeSize} px")
print(f"  Fill opacity: {prefs.editorFillOpacity}%")
print(f"  Show curve handles: {prefs.editorShowCurves}")
print(f"  Show coordinates: {prefs.editorCoordinates}")

print("\n--- Nudge distances ---")
print(f"  Arrow key nudge: {prefs.editorNudge1} units")
print(f"  Shift+arrow nudge: {prefs.editorNudge10} units")

print("\n--- Snap settings ---")
print(f"  Snap to guidelines: {prefs.snapToGuidelines}")
print(f"  Snap to outline: {prefs.snapToOutline}")
print(f"  Snap distance: {prefs.editorSnapDistance} px")

print("\n--- Grid ---")
print(f"  Grid X: {prefs.gridDistanceX}, Grid Y: {prefs.gridDistanceY}")
print(f"  Grid opacity: {prefs.gridOpacity}")

# ============================================================
# 3. Safely changing a preference
# ============================================================
# ALWAYS save the original value so you can restore it.
# Never leave preferences in a changed state when your
# script finishes, unless that's the explicit goal.

orig_node_size = prefs.editorNodeSize

print(f"\nChanging node size from {orig_node_size} to 10...")
prefs.editorNodeSize = 10

# Tell the app to refresh all displays with the new value
flItems.notifyPreferencesChanged()

# ... do some work where larger nodes are helpful ...

# Restore
prefs.editorNodeSize = orig_node_size
flItems.notifyPreferencesChanged()
print("Node size restored.")

# ============================================================
# 4. Saving and restoring a full preferences snapshot
# ============================================================
# prefs.save() returns a dict of all current preference values.
# prefs.load(dict) restores from that dict.
# Use this to make large temporary changes safely.

snapshot = prefs.save()
print(f"\nSaved preferences snapshot ({len(snapshot)} entries).")

# Make some temporary changes for a proofing workflow:
prefs.editorFillOpacity = 0        # transparent fill
prefs.editorShowCurves  = False     # hide handles
prefs.editorCoordinates = False     # hide coordinate display
prefs.colorWorkspace    = QColor(240, 240, 240)   # light grey background
flItems.notifyPreferencesChanged()

print("Temporary proofing preferences applied.")
print("(In a real script, do your proofing work here.)")

# Restore everything from the snapshot
prefs.load(snapshot)
flItems.notifyPreferencesChanged()
print("Preferences fully restored from snapshot.")

# ============================================================
# 5. Temporarily disabling all snapping
# ============================================================
# Useful before running a layout script where snapping
# would interfere with programmatic positioning.

snap_props = [
    'snapToGrid', 'snapToGuidelines', 'snapToFontGuidelines',
    'snapToFontMetrics', 'snapToMetrics', 'snapToOutline',
    'snapToBounds', 'snapToCenters', 'snapToDistance'
]

# Save originals
orig_snaps = {p: getattr(prefs, p) for p in snap_props}

# Disable all snapping
for p in snap_props:
    setattr(prefs, p, False)
flItems.notifyPreferencesChanged()
print("\nAll snapping disabled.")

# ... run your positioning script here ...

# Restore all snap settings
for p, v in orig_snaps.items():
    setattr(prefs, p, v)
flItems.notifyPreferencesChanged()
print("Snap settings restored.")

# ============================================================
# 6. Configuring grid spacing
# ============================================================
# For a 1000-unit UPM font, a 10-unit grid is common.
# setGridDistances() sets both axes at once.

orig_gx = prefs.gridDistanceX
orig_gy = prefs.gridDistanceY

flPreferences.setGridDistances(10.0, 10.0)
flItems.notifyPreferencesChanged()
print(f"\nGrid set to 10×10 (was {orig_gx}×{orig_gy}).")

# Restore
flPreferences.setGridDistances(orig_gx, orig_gy)
flItems.notifyPreferencesChanged()

# ============================================================
# 7. Reading the data path (where scripts and resources live)
# ============================================================

print(f"\nFontLab data path: {prefs.dataPath}")
print(f"Default data path: {prefs.dataPathDefault}")
print(f"Auto-save path: {prefs.pathAutoSave}")

# ============================================================
# 8. Checking dark mode
# ============================================================
# Scripts that generate colours can adapt to the current theme.

if prefs.isDark:
    bg_colour = QColor(30, 30, 30)
    fg_colour = QColor(220, 220, 220)
    print("\nDark mode: using light-on-dark colours.")
else:
    bg_colour = QColor(255, 255, 255)
    fg_colour = QColor(0, 0, 0)
    print("\nLight mode: using dark-on-light colours.")

print("\nPreferences tutorial complete.")
