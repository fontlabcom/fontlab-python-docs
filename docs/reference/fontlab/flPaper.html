    fontlab.flPaper

    flPaper

    Metrics view background layer.

    What is flPaper?

    The "paper" is the background layer of the metrics view canvas. It is the model object that manages the ordered list of all flGlyphInfo objects currently being rendered — the glyphs that are shown in the text string of the metrics/spacing view. It also tracks which glyph is the "active" one (the one whose outline nodes are currently visible and editable).

    In typical scripting you access the paper through the canvas rather than creating one directly. The paper is your gateway to understanding what is being displayed: which glyphs are on screen, which is selected for editing, and what the combined bounding rectangle of all displayed content is.

    Tutorial

    flPaper is the object you use to ask "what is on screen right now, and which glyph is active?" in the metrics view.

    import fontlab as fl

# ============================================================
# Access the paper of the current metrics/glyph window canvas
# and inspect what is displayed.
# ============================================================

ws     = fl.flWorkspace.instance()
canvas = ws.getActiveCanvas()
if canvas is None:
    print("Open a glyph or metrics window first.")
    raise SystemExit

paper = canvas.paper
if paper is None or not paper.hasContent():
    print("Paper has no content — type something in the metrics view.")
    raise SystemExit

print(f"Paper has content: {paper.hasContent()}")
print(f"Active glyph open: {paper.hasActive()}")

# Get the bounding box of all displayed glyphs in canvas units:
bounds = paper.glyphsBoundRect()
print(f"All-glyphs canvas bounds: "
      f"({bounds.left():.0f}, {bounds.top():.0f}) → "
      f"({bounds.right():.0f}, {bounds.bottom():.0f})")

# Get the active glyph info:
if paper.hasActive():
    gi = paper.activeGlyphInfo()
    print(f"Active glyph: '{gi.name}'")

# ============================================================
# Iterate all glyphs currently displayed on the paper.
# ============================================================

# The paper's glyphInfoAt(i) API requires knowing the count.
# Use the canvas's glyphInfos() shortcut if available,
# otherwise iterate with a try-except:
print("\nGlyphs on paper:")
i = 0
while True:
    try:
        gi = paper.glyphInfoAt(i)
        if gi is None:
            break
        print(f"  [{i}] '{gi.name}'")
        i += 1
    except Exception:
        break

# ============================================================
# Programmatically open a glyph for editing in the metrics view.
# ============================================================

font  = paper.package()
glyph = font['O']
new_gi = paper.setActiveGlyph(glyph)
if new_gi:
    print(f"\nOpened '{new_gi.name}' for editing.")
    fl.Update()

    Common Scripting Patterns

    Check if a specific glyph is currently in the text string

    import fontlab as fl

ws     = fl.flWorkspace.instance()
canvas = ws.getActiveCanvas()
if canvas:
    paper = canvas.paper
    font  = fl.CurrentFont()
    if paper and font:
        gi = paper.getGlyphInfo(font['a'])
        if gi:
            print("'a' is on the paper.")
        else:
            print("'a' is not currently displayed.")

    Zoom the canvas to show all glyphs

    import fontlab as fl

ws     = fl.flWorkspace.instance()
canvas = ws.getActiveCanvas()
if canvas:
    paper = canvas.paper
    if paper and paper.hasContent():
        rect = paper.glyphsBoundRect()
        canvas.centerOnRect(rect)   # or use canvas.zoomToRect(rect)
        fl.Update()
