    fontlab.flModel

    flModel

    Think of flModel as FontLab's type registry — its internal catalogue of every kind of object that can exist in a font. Every node, contour, shape, glyph, layer, guideline, and anchor has a numeric type ID registered here. flModel lets you look those IDs up, create objects dynamically by type, and most importantly, send "something changed" signals to the rest of the application after you've made scripted edits.

    As a type designer writing scripts, you'll reach for flModel in two situations:

    • After editing glyph data — call notifyGlyphChanged() so FontLab refreshes its displays (metrics, previews, the glyph window).
    • Type checking — use ModelType IDs and typeToStr() to confirm what kind of object you're holding.

    The class is a singleton; you don't need an instance. All methods are called directly on the class, like flModel.notifyGlyphChanged(fg_id).

    Enum: flModel.ModelType

    A dictionary of integer constants, one for every object type in the font model. You use these with createObject(), typeToStr(), and type-checking code.

    Common Scripting Patterns

    # The most common pattern: after any scripted edit, fire a notification
glyph = fl.CurrentFont()['A']
# ... (make changes to glyph.layers[0].shapes[0] here) ...
flModel.notifyGlyphChanged(glyph.id)

# Batch notification for efficiency
changed_glyphs = set()
for name in ['A', 'B', 'C']:
    g = fl.CurrentFont()[name]
    # ... edit g ...
    changed_glyphs.add(g.id)
flModel.notifyGlyphsChanged(changed_glyphs)

# Type checking: confirm what kind of object you have
obj = something_from_the_api()
print(flModel.typeToStr(obj.type))  # e.g. "Node", "Shape", "GuideLine"

# Check if an object is of a specific type
if obj.type == flModel.ModelType["Node"]:
    print("It's a node!")

    Tutorial

    import fontlab as fl
from fontlab import flModel

# ============================================================
# 1. Identifying object types
# ============================================================
# Every font object has a .type property — an integer code.
# typeToStr() turns that code into a human-readable name.

font  = fl.CurrentFont()
glyph = font['A']
layer = glyph.layers[0]
shape = layer.shapes[0]
node  = shape.contours[0].nodes()[0]

for obj, label in [(glyph, 'glyph'), (layer, 'layer'),
                   (shape, 'shape'), (node, 'node')]:
    type_id   = obj.type
    type_name = flModel.typeToStr(type_id)
    print(f"  {label}: type={type_id}  name='{type_name}'")

# Using ModelType to get type IDs by name:
print("Node type ID:", flModel.ModelType["Node"])
print("Shape type ID:", flModel.ModelType["Shape"])
print("GuideLine ID:", flModel.ModelType["GuideLine"])

# ============================================================
# 2. Creating objects dynamically
# ============================================================
# You can create a new, blank object by its type ID.
# This is useful for building objects programmatically.

node_type_id = flModel.ModelType["Node"]
new_node = flModel.createObject(node_type_id)
if new_node is not None:
    print("Created a new:", flModel.typeToStr(new_node.type))

# ============================================================
# 3. Class mask checks (advanced)
# ============================================================
# isClassMask tells you if a type constant is a bitmask
# (abstract base class) rather than a concrete type:

print("Is 'Node' a class mask?",
      flModel.isClassMask(flModel.ModelType["Node"]))     # False — it's concrete
print("Is 'Object' a class mask?",
      flModel.isClassMask(flModel.ModelType["Object"]))   # True — it's abstract

# getClassMask: what abstract base categories does a type belong to?
mask = flModel.getClassMask(flModel.ModelType["Shape"])
print("Shape class mask:", bin(mask))

# ============================================================
# 4. Notifying FontLab after scripted edits
# ============================================================
# This is the most important real-world use of flModel.
# After you change glyph data from a script, FontLab's UI
# doesn't know about it until you send a notification.

# Get the fontgate glyph ID (not Unicode, not array index):
fg_id = glyph.id

# Lightweight: just refresh the visual display
flModel.notifyGlyphUpdate(fg_id)

# Full update: recalculate metrics, refresh previews, etc.
# Use this after actually changing node positions or outlines.
flModel.notifyGlyphChanged(fg_id)

# Batch update — efficient for multi-glyph scripts:
changed_ids = {font['A'].id, font['B'].id, font['C'].id}
flModel.notifyGlyphsChanged(changed_ids)

# ============================================================
# 5. Browsing ObjectParameter constants
# ============================================================

print("ObjectParameter constants:")
for k, v in flModel.ObjectParameter.items():
    print(f"  {k} = {v}")
