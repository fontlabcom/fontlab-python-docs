    fontlab.flShape

    flShape

    The Element.

    What Is an flShape?

    In FontLab's interface, what you see as an element in the Glyph window is an flShape in Python. Every time you draw a contour, paste artwork, or use a parametric element (like a stroke or an inline), FontLab wraps that drawing in an flShape and places it on a layer.

    Think of flShape as the editing shell around your drawing. It carries: - The geometric transform that positions the element within the glyph - Selection and lock state - Colour/opacity for colour font work - A reference to the actual drawing data (flShapeData)

    The Three Kinds of Shape

    Understanding which type of shape you're working with will save you a lot of confusion in scripts:

    Simple shape — This is the most common kind. It directly holds a list of flContour objects. When you draw an "A", the stem, the crossbar, and the counter are each contours inside one or more simple shapes. isComposite is False. The current simpleShape() implementation always returns False, so use shape type and component/composite checks when selecting editable contours.

    Composite shape — A composite is a shape that contains other shapes as children (its "include list"). In the UI you make a composite by grouping elements together. The sub-shapes live inside and can be rearranged, ejected back out, or merged down. isComposite is True.

    Component shape — A component references the shape data of another glyph. When you place an accented character like "Á" and the acute accent is reused from another glyph, it arrives as a component shape. isComponent is True and shapeData.componentGlyph tells you the source glyph name. You cannot edit the contours of a component directly — you must decompose it first.

    Inherits from flObject.

    Tutorial

    This tutorial walks through the most common shape scripting tasks: reading shapes from a glyph, building new shapes, and working with composites.

    import fontlab as fl
from fontlab import flShape, flContour, flNode
from PythonQt.QtCore import QPointF
from PythonQt.QtGui import QTransform

font  = fl.CurrentFont()
glyph = font['A']
layer = glyph.layers[0]

# --- Reading shapes from a layer ---
# Each item in layer.shapes is an flShape. Let's see what we're working with.
for sh in layer.shapes:
    kind = "composite" if sh.isComposite else ("component" if sh.isComponent else "simple")
    print(f"Shape: {kind}, contours={sh.contoursCount}, bounds={sh.boundingBox}")

# --- Inspecting contours of a simple shape ---
# Make sure it's a simple shape before trying to iterate contours.
shape = layer.shapes[0]
if shape.simpleShape():
    for contour in shape.getContours():
        nodes = contour.nodes()
        print(f"  Contour: {len(nodes)} nodes, closed={contour.closed}")

# --- Building a new rectangular shape and adding it to the layer ---
# First create the shape object, then build contour geometry, then add to layer.
new_shape = flShape()
rect = flContour()
rect.closed = True

# Add four corner nodes for a 200×300 rectangle
for x, y in [(0, 0), (200, 0), (200, 300), (0, 300)]:
    rect.add(flNode(x, y, nodeType='on'))
new_shape.addContour(rect)

# Add the new shape to the layer so it appears in the glyph
layer.addShape(new_shape)
print("Added rectangular shape. Bounds:", new_shape.boundingBox)

# --- Moving a shape by changing its transform ---
# Prepare the transform cache before any geometric operation.
new_shape.prepareTransformationData()
tx = QTransform().translate(50, 0)   # move 50 units to the right
new_shape.applyTransform(tx)
new_shape.resetTransformationData()
print("After move, bounds:", new_shape.boundingBox)

# --- Checking and clearing selection ---
# Useful at the start of a script that will set a specific selection.
new_shape.unselectAllNodes()

# --- Working with a composite shape ---
# Check if any shapes on this layer are composites and inspect their children.
for sh in layer.shapes:
    if sh.isComposite:
        print(f"Composite with {len(sh.includesList)} children")
        for child in sh.includesList:
            print(f"  child type: {child.shapeType}")

        # To break a composite apart, use ejectTo.
        # apply_tx=True keeps each child in its current visual position.
        children = sh.ejectTo(clone=True, apply_tx=True)
        print(f"Ejected {len(children)} shapes from composite")

# --- Checking for components (references to other glyphs) ---
# Components cannot be edited until you decompose them.
for sh in layer.shapes:
    if sh.isComponent:
        src = sh.shapeData.componentGlyph
        print(f"Component references glyph: {src}")
        # Decompose to get real editable contours:
        sh.decomposite()
        print("  Decomposed to plain contours")

# --- Working with anchors on a shape ---
# Anchors are used for diacritic attachment. Most shapes won't have them.
for sh in layer.shapes:
    anchors = sh.getAnchors()
    if anchors:
        for anchor in anchors:
            print(f"Anchor at: {anchor.anchorPoint}")

# --- Checking interpolation compatibility for variable fonts ---
# Before writing interpolation scripts, verify shape compatibility.
if len(layer.shapes) >= 2:
    s1, s2 = layer.shapes[0], layer.shapes[1]
    compat = s1.isCompatible(s2, strong=True)
    print("Shapes are compatible for interpolation:", compat)

# Always call Update() after making changes so FontLab redraws the glyph.
fl.Update()

    Common Scripting Patterns

    Iterating over all shapes and their contours

    for shape in layer.shapes:
    if not shape.simpleShape():
        continue   # skip composites and components
    for contour in shape.getContours():
        for node in contour.nodes():
            print(node.x, node.y)

    Finding the shape with the largest bounding box

    biggest = max(layer.shapes, key=lambda sh: sh.boundingBox.width() * sh.boundingBox.height())
print("Largest shape bounds:", biggest.boundingBox)

    Locking all shapes except the active one

    for shape in layer.shapes:
    if not shape.active:
        shape.contentLocked = True

    Moving every shape by a fixed offset without touching the node coordinates

    offset = QTransform().translate(20, -10)
for shape in layer.shapes:
    shape.prepareTransformationData()
    shape.applyTransform(offset)
    shape.resetTransformationData()
fl.Update()

    Excluding all empty shapes from export

    for shape in layer.shapes:
    if shape.isEmpty:
        shape.excluded = True
print("Empty shapes flagged for exclusion from export")

    Decomposing all components in a glyph to editable contours

    glyph = font['agrave']
for layer in glyph.layers:
    for shape in layer.shapes:
        if shape.isComponent:
            shape.decomposite()
fl.Update()

    Checking if a glyph has any composite or component shapes

    def has_non_simple_shapes(glyph):
    for layer in glyph.layers:
        for shape in layer.shapes:
            if shape.isComposite or shape.isComponent:
                return True
    return False

    Stroke scripting

    penParameters is a readable/writable dictionary using the stroke keys stored in VFJ/VFC:

    • thickness (or the input alias width), join (miter, bevel, round), and miter_limit agree with the element's QPen.
    • proportion and contrast use percentages; rotation uses degrees.
    • proportion is the share of thickness on the left of the path direction: 0 is entirely on the right, 50 is centered, and 100 is entirely on the left. Reversing the path with the same proportion swaps the geometric side.
    • cap0 and cap1 select the start/end cap. cap_offset0/1, cap_shaping0/1, and cap_curvature0/1 use percentages; cap_rotation0/1 uses degrees.
    • remove_overlap is a boolean. tolerance specifies stroke approximation tolerance.

    Assigning a dictionary replaces the extended parameters; omitted extended values return to their defaults. Omitted width, join, miter, and cap type are initialized from the current QPen. The getter includes those values explicitly, so its result can be copied to another element. Positive thickness enables a stroke; zero disables it. The setter preserves the pen's brush/color. Non-dictionaries raise TypeError; invalid or non-finite numeric values and negative thickness raise ValueError before changing the element.

    Assigning shape.pen = qpen enables a live stroke when the pen style is not NoPen. Width, join, and miter limit come from QPen. Enabling a stroke or changing QPen's cap style initializes both native end caps from that style. Changes to color, width, or join that keep the same cap style preserve explicit cap0/cap1 and their shaping parameters. Use penParameters for different start/end caps or custom cap geometry.

    A fresh QPen uses miter limit 2; native PenParameters and the Add Stroke dialog default to 3. Specify miter_limit explicitly for reproducible imports. Native miter joins clip the tip when it exceeds the limit times the local side width (half the thickness for a centered circular stroke). This is not an SVG/Figma miter-to-bevel conversion rule.

    shape.penParameters = {
    "thickness": 40,
    "cap0": "round", "cap1": "round",
    "join": "round", "contrast": 75, "rotation": 30,
}
style = shape.penParameters
other.penParameters = style
expanded = shape.expandStroke()  # equivalent to expandStroke(False)

    expandStroke([outer_only]) -> bool replaces one element's stroke with filled outlines using the native stroke engine, without requiring a canvas selection. The fill uses the former pen brush; the stroke is removed. Opacity, transform, locking, and non-spacing state are preserved. It returns False without replacing the element when there is no usable stroke or no outline can be generated. outer_only=True requests the native outer-only expansion mode. This is a geometry operation, not a guarantee of interpolation-compatible results between masters.

    The return value is a success flag; read shape.contours after expansion for the resulting contours. shape.inkBox() measures a live stroke without expanding it, using the native preview approximation. boundingBox remains a padded estimate.

    Both operations modify the model. Scripts editing document elements must manage history and send the usual change notifications themselves.

    Smart corners and ink traps

    shape.addSmartCorner(node, radius=20, smooth=False) adds or updates a live smart corner and returns True when applicable. Use a negative radius for an ink trap. smooth=True enables G2 smoothing of rounded corners. The node must belong to the shape's editable source and have two nonzero, non-collinear tangents. Smooth points, handles, open endpoints, foreign nodes and locked shapes return False. Invalid radii (zero, nonfinite or outside ±10000000) raise ValueError in Python.

    shape.addSmartCorners(radius=20, smooth=False) adds corners to every applicable node that does not already have one, and returns the number added. Repeated calls preserve existing smart corners. Components, groups and incompatible filters are skipped.

    Both methods create the native Smart Corners filter automatically, preserving the element's transform and paint. Existing Smart Corners filters are reused. New filters use the owning font's corner tension and ink-trap length, or defaults for detached elements. The editable contours are cloned when the filter is first installed: reacquire nodes through shape.smartCornerSource().contours afterwards. This method returns the shape itself for plain outlines and a null shape for unsupported or locked content.

    # Bulk addition, with automatic filter management:
added = shape.addSmartCorners(20)
# Update one source node into an ink trap:
source = shape.smartCornerSource()
shape.addSmartCorner(source.contours[0].nodes()[0], -15)

    Notify changes once at glyph level after a script's edits. A complete current-glyph sample is in examples/python/add_smart_corners.py.

    MCP: inspect with get_glyph_nodes, then send edit_glyph_nodes an operation such as {"op":"smart_corner","shape_index":0,"contour_index":0,"node_index":2,"radius":20,"smooth":false}. smart_corner_applicable identifies eligible nodes; smart_radius is null for ordinary nodes. The tool creates/reuses the filter and supports atomic batches, dry_run and Undo. Reads and subsequent edits use the filter's source indices.
