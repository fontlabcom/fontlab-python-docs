    fontlab.flBasicTool

    flBasicTool

    Base class for editor tools.

    What is flBasicTool?

    Every tool in FontLab's toolbar — the Pointer, the Pen, the Knife, the Eraser, the Text tool — is an flBasicTool under the hood. This class defines the minimum interface that all canvas tools share: the ability to activate and deactivate, and an identifier for the cursor shape to display while the tool is active.

    If you want to write a custom editor tool that handles mouse and keyboard events on the canvas, you subclass flBasicTool and implement event handler methods (mousePressEvent, mouseMoveEvent, keyPressEvent, etc.). You then receive flEvent objects in those methods describing exactly what the user did.

    For most designers writing utility scripts, you will never create a tool — you call methods on model objects directly. But if you want a persistent tool that always lives in the toolbar and responds to drawing gestures in real time, flBasicTool is your starting point.

    Tutorial

    The most common scripting use of flBasicTool is activating a built-in tool programmatically. The tool instances are accessible through the workspace.

    import fontlab as fl

# ============================================================
# List all available tools in the current workspace.
# Each tool is an flBasicTool subclass registered with the
# workspace tool manager.
# ============================================================

ws = fl.flWorkspace.instance()
tools = ws.tools   # list of registered flBasicTool objects

print(f"Available tools ({len(tools)}):")
for tool in tools:
    active = " [ACTIVE]" if tool == ws.currentTool else ""
    print(f"  {type(tool).__name__:30s}  cursor={tool.cursorId}{active}")

# ============================================================
# Activate a specific tool by name.
# Replace 'flPointerTool' with the tool class you want.
# ============================================================

pointer = next((t for t in tools if 'Pointer' in type(t).__name__), None)
if pointer:
    pointer.activateTool()
    print(f"\nActivated: {type(pointer).__name__}")
else:
    print("\nPointer tool not found.")

    Common Scripting Patterns

    Activate the Pointer tool to return to normal editing mode
    import fontlab as fl

ws = fl.flWorkspace.instance()
for tool in ws.tools:
    if 'Pointer' in type(tool).__name__:
        tool.activateTool()
        break
    Check which tool is currently active
    import fontlab as fl

ws      = fl.flWorkspace.instance()
current = ws.currentTool
if current:
    print(f"Active tool: {type(current).__name__}")
    print(f"  Cursor ID: {current.cursorId}")
