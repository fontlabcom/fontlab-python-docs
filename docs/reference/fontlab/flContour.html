    fontlab.flContour

    flContour

    flContour representation

    Constructors: flContour() flContour(flObject) flContour(flContour) flContour(fgContour) flContour(id) flContour(list(Node)[, bool closed=false]) flContour(list(QPointF)[, flNode::NodeType=flNode::On[, bool closed=false]]) flContour(QRectF) flContour(QLineF)

    Native bases: object

    Supplemental documentation: A closed or open path made of flNode objects. Read contour.nodes and contour.closed. Obtain contours with layer.getContours().

    Example::

    for contour in layer.getContours():
    for node in contour.nodes:
        print(node.x, node.y)
