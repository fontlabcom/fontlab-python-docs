    fontlab.flNodeInfo

    flNodeInfo

    Represents one node on the canvas. This is the "live" version of an flNode — it knows where the node is on screen and can move it in glyph-space coordinates. This is what you receive when the user selects nodes in a scripted tool.

    When do you use it?

    In any tool that moves selected nodes. canvas.selectedNodes() returns a list of flNodeInfo objects, and you move those nodes by calling setGlyphPoint() on each one.

    Tutorial

    flNodeInfo is the primary API for moving nodes in a custom canvas tool. Here is the standard pattern: get the selected node infos, move them, then refresh.

    from PythonQt.QtCore import QPointF
import fontlab as fl

# ============================================================
# Move all selected nodes up by 10 units.
# This is the pattern used by any tool that nudges nodes.
# ============================================================

ws     = fl.flWorkspace.instance()
canvas = ws.getActiveCanvas()
if canvas is None:
    print("Open a glyph window first.")
    raise SystemExit

gi = canvas.activeGlyphInfo()
if gi is None:
    print("No active glyph.")
    raise SystemExit

selected = gi.selectedNodes()   # returns list of flNodeInfo
if not selected:
    print("Select at least one node first.")
    raise SystemExit

print(f"Moving {len(selected)} selected node(s) up by 10 units:")
for ni in selected:
    pt = ni.getGlyphPoint(False)          # current position (unrounded)
    new_pt = QPointF(pt.x(), pt.y() + 10)
    ni.setGlyphPoint(new_pt)              # move the node
    print(f"  ({pt.x():.0f}, {pt.y():.0f}) → ({new_pt.x():.0f}, {new_pt.y():.0f})")

fl.Update()   # refresh the canvas after all moves

# ============================================================
# Align all selected nodes to the same x-coordinate
# (the average x of the selection).
# ============================================================

if selected:
    xs    = [ni.getGlyphPoint(False).x() for ni in selected]
    avg_x = sum(xs) / len(xs)
    for ni in selected:
        pt = ni.getGlyphPoint(False)
        ni.setGlyphPoint(QPointF(avg_x, pt.y()))
    fl.Update()
    print(f"Aligned {len(selected)} nodes to x={avg_x:.0f}")

    Common Scripting Patterns

    Validate node infos after a delete operation
    import fontlab as fl

ws     = fl.flWorkspace.instance()
canvas = ws.getActiveCanvas()
gi     = canvas.activeGlyphInfo() if canvas else None
if gi:
    nodes = gi.selectedNodes()
    valid_nodes = [ni for ni in nodes if ni.isValid()]
    print(f"{len(valid_nodes)} of {len(nodes)} node infos are still valid.")
