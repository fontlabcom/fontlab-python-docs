    fontlab.flTextBlock

    flTextBlock

    Text layout and editing engine.

    Understanding flTextBlock

    The flTextBlock is both a layout engine (it knows how to arrange glyphs on screen, apply features, handle line wrapping) and an interactive widget (it receives mouse clicks and key presses and updates accordingly).

    There are two editing modes you will encounter in scripts: - Text mode (EditMode.Text): the user is typing characters. Key presses insert/delete characters from the string. - Metrics mode (EditMode.Metrics): the user is adjusting sidebearings and kerning. Clicking a glyph selects it for metric editing.

    The text block maintains a cursor position (which glyph is active), a selection (which glyphs are selected), and a symbol list (the full string of characters being shown).

    Creating an flTextBlock

    from fontlab import flTextBlock
tb = flTextBlock.createInstance()
tb.init(canvas)   # attach to a canvas

    Lifecycle & Setup

    Signature Description
    init(flCanvas& canvas) Attaches this text block to a canvas and initialises all internal state. Must be called before any other method. Pass the flCanvas you want the text to appear on.
    removedFromCanvas() Cleans up internal rendering state when the text block is detached from its canvas. Call this before destroying a text block that was previously attached.
    setParentTextBlock(flTextBlock) Sets a parent text block for nested text block hierarchies (used internally for composite metrics views).

    Content & Layout

    Signature Description
    glyphsChanged() Tells the text block that the underlying glyph geometry has changed and a full re-layout is needed. Call this after editing glyph outlines in a script so the metrics view updates correctly.
    reformat() Forces a complete re-layout of the text from scratch. Call this after changing font size, features, or any other property that affects how glyphs are arranged.
    updateSymbols() Refreshes the text block's internal symbol list from the linked text object. Useful when the text string has been changed externally.
    removeFeatures() Clears all active OpenType feature overrides, returning the text to its default feature state (typically kern + liga). Call this to reset to a clean state before applying a new set of features.
    setFeatures(list(QString), bool reformat) Sets the complete list of active OpenType feature tags, replacing any previously set features. Pass reformat=True to immediately re-layout. Example: tb.setFeatures(["kern", "liga", "smcp"], True).
    addFeature(QString feature) Adds one OpenType feature tag to the active set. Does not remove existing features. Example: tb.addFeature("smcp") to turn on small caps.
    removeFeature(QString feature) Removes one OpenType feature tag. Example: tb.removeFeature("smcp") to turn off small caps.
    list(QString) features() Returns the list of currently active feature tags. Use this to read the current feature state before modifying it.
    setTextBlockMode(EditMode text_block_mode[, QPoint viewport_pos=QPoint()]) Switches the editing mode. EditMode.Text for text entry, EditMode.Metrics for spacing/kerning editing. Optionally pass the current viewport position so the view adjusts correctly.
    setFixedHeight(bool fixed, bool shrink) Configures height behaviour. If fixed is True, the text block has a fixed height. If shrink is also True, it shrinks to fit content if content is smaller than the fixed height.
    setFrameWidth(double) Sets the maximum width for word-wrapped text. When content exceeds this width, it wraps to a new line.
    setFrameSize(QSizeF canvas_size) Sets both width and height for framed (word-wrapped) text layout. After calling this, text will wrap within the specified frame.
    setShowCursor(bool) Shows or hides the text insertion cursor (the blinking I-beam). Set to False when displaying text that isn't actively being edited.
    setShowNodes(bool) Shows or hides the glyph outline nodes inside the text block. Set to True when you want to display node positions in the metrics view — useful for comparing node positions across glyphs.
    setLayoutProcessing(bool) Enables or disables GSUB (glyph substitution) processing. When disabled, OpenType substitutions (ligatures, small caps, etc.) are not applied even if the features are listed.
    setKerningProcessing(bool) Enables or disables kerning. When disabled, all pairs are shown at zero kerning regardless of the font's kern data. Useful for checking un-kerned spacing.
    setMarksProcessing(bool) Enables or disables mark attachment (GPOS mark/mkmk features). When disabled, combining marks are displayed without positioning.
    drawContent(QPainter*, flCanvas, QRectF painted_nodes_screen_rect) Renders the text block's content to a QPainter. Used in custom rendering code. Pass the canvas for coordinate mapping and the screen rect of visible nodes for performance optimisation.

    Glyph Queries

    Signature Description
    flGlyphInfo/Nothing getActiveGlyph() Returns the flGlyphInfo for the glyph at the current cursor position, or Nothing if the cursor is not inside any glyph. This is the "currently selected glyph" in metrics mode.
    flGlyphInfo/Nothing getHitGlyph(QPointF canvas_pos) Returns the flGlyphInfo for whichever glyph's bounding box (advance width rectangle) contains the given canvas point. Use this for "click to select glyph" in metrics mode.
    flGlyphInfo/Nothing getHitToShapeGlyph(QPointF canvas_pos) Like getHitGlyph but tests against the actual ink shapes rather than the bounding box. A click in the white space between strokes of an 'H' would return Nothing with this method, but a result with getHitGlyph. Use this for more precise click-to-select.
    list(flContourInfo)/Nothing getHitToShapes(QPointF canvas_pos) Returns the flContourInfo objects whose filled shapes contain the given canvas point. Useful for finding exactly which contour was clicked when a glyph has complex overlapping shapes.
    list(flGlyphInfo)/Nothing getIntersectsGlyphs(QRectF canvas_rect) Returns all glyph infos whose bounding boxes intersect the given canvas rectangle. Use this for rubber-band selection (drag a selection box and find all glyphs touched by it).
    flGlyphInfo/Nothing getNextGlyphInLine(int glyph_index) Returns the flGlyphInfo for the glyph immediately after glyph_index in the text line. Returns Nothing at the end of the line. Use for sequential navigation.
    flGlyphInfo/Nothing getPrevGlyphInLine(int glyph_index) Returns the flGlyphInfo for the glyph immediately before glyph_index. Returns Nothing at the start of the line.
    flGlyphInfo/Nothing getGlyphAt(int glyph_index) Returns the flGlyphInfo at absolute index glyph_index in the symbol list. The first glyph is index 0. Returns Nothing if out of range.
    flGlyphInfo/Nothing getGlyphInfo(fgSymbol, &) Returns the flGlyphInfo for a specific fgSymbol object. Useful when you already have a symbol reference (e.g. from symbolList[2]) and want to get its canvas info.
    list(flGlyphInfo)/Nothing getGlyphsInLine(flGlyphInfo | int lineIndex) Returns all glyph infos in the same text line. Pass either a glyph info (to find its line-mates) or a line index directly. Returns Nothing if the line index is out of range.
    list(flGlyphInfo)/Nothing getAllGlyphs([int line_index = -1]) Returns every glyph info in the text block. If line_index >= 0, returns only glyphs in that specific line. This is your "get everything" method for iterating the metrics view.
    list(flGlyphInfo)/Nothing getNearbyGlyphs(QPointF text_block_point, double max_dist) Returns all glyph infos within max_dist text-block units of the given point. Useful for implementing magnetic selection or automatic nearest-glyph queries.
    setActiveGlyph(flGlyphInfo) Programmatically moves the editing cursor to the given glyph. Use this to set focus on a specific glyph in metrics mode — for example, after a script identifies a problem glyph, jump the cursor to it.
    setCheckMouseHoverNode(bool) Enables or disables per-frame node hover detection during mouse movement. Disabling this improves performance when you do not need hover highlights on individual nodes.
    setExclusiveEditing(bool) When True, this text block captures all mouse events exclusively, preventing clicks from reaching other canvas items. Use in custom tool implementations when the text block should own all interaction.

    Selection & Navigation

    Signature Description
    fgSymbolList/Nothing getSelectedCharacters() Returns the selected characters as an fgSymbolList, or Nothing if no characters are selected. This gives you the Unicode/name information for the selection, independent of canvas coordinates.
    list(flGlyphInfo)/Nothing getSelectedGlyphs() Returns the selected glyph infos. This is the same selection as getSelectedCharacters but as canvas info objects, with position and bounds available.
    list(flShape)/Nothing visibleShapes() Returns the flShape objects that are currently visible within the viewport. Useful for selective rendering or for knowing which shapes to include in a measurement.
    flNodeInfo/Nothing getMouseHitNode() Returns the flNodeInfo for the node currently under the mouse cursor, or Nothing. Useful in canvas overlay scripts that want to highlight or annotate the hovered node.
    flNodeInfo/Nothing getScvNode() Returns the current smooth-curve-vector node for G2 curvature editing mode, or Nothing if not in G2 mode.

    Metrics

    Signature Description
    setRightMetric(QPointF canvas_pos, flGlyphInfo glyph_info, bool measurement) Sets the right sidebearing of glyph_info by moving the right metric line to canvas_pos. If measurement is True, a ruler line is shown but the metric is not committed — useful for a preview. If False, the change is committed to the font.
    setLeftMetric(flGlyphInfo glyph_info, bool measurement) Sets the left sidebearing for glyph_info. Works the same way as setRightMetric — measurement=True for preview, False to commit.

    Line & Position Queries

    Signature Description
    QPointF getCurrentPosition() Returns the current cursor insertion position in canvas coordinates. Use this to position a custom cursor overlay exactly where the text cursor is.
    QRectF activeRowRect() Returns the bounding rectangle of the currently active row (the row containing the text cursor), in canvas coordinates. Use this to draw a row-highlight background.
    QRectF paintedNodesScreenRect() Returns the total screen rectangle that contains all rendered glyph nodes. Use this as the repaint region when something in the text changes.
    bool hasHoveredNodeEdit() Returns True if a node is currently hovered for editing (i.e. the cursor is over an editable node).
    bool haveText() Returns True if the text block has at least one character. An empty text block returns False.
    bool isFramed() Returns True if the text block is in frame (word-wrap) mode.
    bool textFits() Returns True if all text content fits within the frame without overflowing. Only relevant in frame mode.
    int charsCount() Returns the number of character slots (symbols) in the string. This is the number of input characters, before any ligature substitutions.
    int glyphsCount() Returns the number of rendered glyph slots. This may differ from charsCount because ligatures replace multiple characters with a single glyph.
    int lastCharIndex() Returns the index of the last character in the symbol list.
    int lastIndex() Returns the last valid glyph index after layout.
    int getLineIndex(flGlyphInfo glyph_info) Returns the zero-based line number that contains the given glyph. The first line is 0.
    int getLineIndex(int glyph_index) Returns the line number for the glyph at index glyph_index.
    int getLineLocation(flGlyphInfo glyph_info) Returns the horizontal pixel offset of glyph_info from the start of its line.
    QTransform getGlyphTransform(int glyph_index) Returns the canvas transform matrix for the glyph at glyph_index. Applying this transform to glyph-space points gives their canvas-space positions.
    QRectF glyphsBoundsOnCanvas(EditMode) Returns the total bounding rectangle of all glyphs in canvas space for the given edit mode.

    Tutorial

    from PythonQt.QtCore import QPointF
import fontlab as fl

# ============================================================
# Open a metrics window first (Window → Metrics), then run
# this script in the scripting panel.
# ============================================================

ws     = fl.flWorkspace.instance()
canvas = ws.getActiveCanvas()

if canvas is None:
    print("Please open a metrics window first.")
    raise SystemExit

# ============================================================
# 1. Access the text block.
#    The metrics view has exactly one text block controlling
#    the main text display.
# ============================================================

# For demonstration, we create a fresh text block:
from fontlab import flTextBlock
tb = flTextBlock.createInstance()
tb.init(canvas)

# Attach the current font:
font = fl.CurrentFont()
tb.package = font
print("Font attached.")

# ============================================================
# 2. Check what is currently displayed.
# ============================================================

print(f"Has text: {tb.haveText()}")
print(f"Characters: {tb.charsCount()}")
print(f"Rendered glyphs: {tb.glyphsCount()}")

# ============================================================
# 3. Iterate all rendered glyphs and print their names
#    and canvas positions.
# ============================================================

all_glyphs = tb.getAllGlyphs()
if all_glyphs:
    print(f"\nAll glyphs ({len(all_glyphs)}):")
    for gi in all_glyphs:
        bbox = gi.brectOnCanvas
        print(f"  '{gi.name}' — canvas x={bbox.left():.0f}..{bbox.right():.0f}")

# ============================================================
# 4. Turn on OpenType features.
#    Let's enable small caps + standard ligatures.
# ============================================================

print(f"\nCurrent features: {tb.features()}")
tb.setFeatures(["kern", "liga", "smcp"], True)   # True = reformat now
print(f"After set:        {tb.features()}")

# Turn off small caps:
tb.removeFeature("smcp")
tb.reformat()
print(f"After remove smcp: {tb.features()}")

# ============================================================
# 5. Change display size.
# ============================================================

tb.fontSize = 96
print(f"Font size set to: {tb.fontSize}px")

# ============================================================
# 6. Switch to metrics mode so the user can adjust spacing.
# ============================================================

# tb.setTextBlockMode(fl.EditMode["Metrics"])
# print("Switched to metrics editing mode.")

# ============================================================
# 7. Find the glyph at a specific canvas position.
#    Simulates what happens when the user clicks at (250, 100).
# ============================================================

click_pos = QPointF(250, 100)
hit = tb.getHitGlyph(click_pos)
if hit:
    print(f"\nGlyph at ({click_pos.x():.0f},{click_pos.y():.0f}): '{hit.name}'")
else:
    print(f"\nNo glyph at ({click_pos.x():.0f},{click_pos.y():.0f})")

# ============================================================
# 8. Frame mode — display text in a fixed-size text box.
# ============================================================

tb.setFrameSize(fl.QSizeF(800, 300))
print(f"\nFrame mode — text fits: {tb.textFits()}")
print(f"Is framed: {tb.isFramed()}")

    Common Scripting Patterns

    Set the metrics view to show a specific string
    import fontlab as fl

ws     = fl.flWorkspace.instance()
canvas = ws.getActiveCanvas()
if canvas:
    tb = canvas.textBlock()
    if tb:
        tb.setString("Hamburgefonstiv")
        fl.Update()
        print("Metrics view updated with test string.")
    Read all glyphs currently in the text block
    import fontlab as fl

ws     = fl.flWorkspace.instance()
canvas = ws.getActiveCanvas()
if canvas:
    tb = canvas.textBlock()
    if tb:
        for i in range(tb.getSymbolsCount()):
            sym = tb.getSymbol(i)
            print(f"  [{i}] {sym.name}")
    Change point size in the metrics view
    import fontlab as fl

ws = fl.flWorkspace.instance()
if ws.getActiveCanvas():
    tb = ws.getActiveCanvas().textBlock()
    if tb:
        tb.fontSize = 72
        fl.Update()
        print("Font size set to 72 pt.")
