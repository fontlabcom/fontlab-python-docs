    fontlab.flPackage

    flPackage

    flPackage is your font file. Everything that makes up a font — every glyph, every master, the design-space axes, named instances, kerning tables, OpenType feature code, stems, alignment zones, guidelines, and all the metadata that ends up in the font's name tables — lives inside one flPackage object.

    Inherits from flObject.

    What is a Package?

    When you open a .vfc, .ufo, .otf, or any other supported format in FontLab, the application creates an flPackage for it. In a script, wrap the low-level current font with fl.flPackage(fl.CurrentFont()), after checking that fl.CurrentFont() is not None.

    The object hierarchy

    It helps to picture the font as a set of nested containers:

    flPackage  (the whole font)
 └── flGlyph  (one character — "A", "g", "comma", …)
      └── flLayer  (one drawing per master — "Regular", "Bold", …)
           └── flShape  (a group of contours, possibly a component reference)
                └── flContour  (one closed or open path)
                     └── flNode  (one on-curve or off-curve point)

    Most scripting work moves through this hierarchy: you start at the font, find a glyph, pick a layer, iterate its shapes, and then walk the contours and nodes. Understanding this chain makes the API feel logical rather than arbitrary.

    Masters and variable fonts

    In a variable font the flPackage acts as the top-level container and each master is a child flPackage stored in font.variationPackages. The master packages share glyph names and structure but hold different coordinate values. When FontLab interpolates, it travels this list and blends the numbers.

    For a single-master font variationPackages has just one entry — the font itself.

    Kerning

    Kerning in FontLab is stored per master. The kerning(master_name) method returns a dictionary of {(glyph1, glyph2): value} pairs for a specific master. When working with class kerning, the keys use group names prefixed with @MMK_L_ and @MMK_R_.

    OpenType features

    The OpenType feature code you write in the Features panel is stored in the featuresContainer inside the package. You can read and write feature code programmatically, which is useful for generating or validating feature files as part of a build pipeline.

    Common Patterns

    Getting the active font and listing its glyphs
    import fontlab as fl
font = fl.CurrentFont()
print(f"{font.info.familyName} — {font.glyphsCount} glyphs")
for g in font.glyphs:
    print(f"  {g.name}  u={hex(g.unicode) if g.unicode else '-'}")
    Changing font metadata
    font = fl.CurrentFont()
info = font.info
info.familyName   = "My Serif"
info.copyright    = "© 2026 My Foundry"
info.openTypeOS2WeightClass = 400
    Finding a glyph and navigating to its nodes
    font  = fl.CurrentFont()
glyph = font.findName("g")
layer = glyph.layers[0]
for shape in layer.shapes:
    for contour in shape.contours:
        for node in contour.nodes:
            print(node.x, node.y, node.type)
    Reading and setting a kern pair
    font        = fl.CurrentFont()
master_name = font.masters[0]   # e.g. "Regular"

# Read all kern pairs for this master:
pairs = font.kerning(master_name)
for (g1, g2), value in list(pairs.items())[:10]:
    print(f"  {g1} / {g2}  =  {value}")

# Set a specific pair:
font.setKerningPair(master_name, "A", "V", -40)
    Adding an axis to make a variable font
    from fontlab import flAxis
font = fl.CurrentFont()
wght = flAxis()
wght.name     = "Weight"
wght.tag      = "wght"
wght.minimal = 100
wght.maximum = 900
wght.default = 400
font.addAxis(wght)

    Tutorial

    from PythonQt.QtCore import QPointF
import fontlab as fl
from fontlab import flPackage

# ============================================================
# 1. Opening and inspecting a font
# ============================================================

# fl.CurrentFont() gives you the flPackage for the active font.
# If no font is open it returns None, so check before using it.
font = fl.CurrentFont()
if font is None:
    print("No font is open!")
else:
    # font.info is a structured object with all UFO-compatible metadata.
    # It mirrors the keys in a UFO fontinfo.plist.
    print(f"Family: {font.info.familyName}")
    print(f"Style:  {font.info.styleName}")
    print(f"UPM:    {font.upm}")
    print(f"Glyphs: {font.glyphsCount}")
    print(f"Masters: {font.masters}")

# ============================================================
# 2. Iterating all open fonts
# ============================================================

# fl.AllFonts() returns every font currently open in FontLab.
# This is useful for batch operations across a whole family.
for f in fl.AllFonts():
    print(f"  Open font: {f.info.familyName} / {f.info.styleName}")

# ============================================================
# 3. Accessing and iterating glyphs
# ============================================================

font = fl.CurrentFont()

# Direct dictionary-style access by glyph name:
glyph_A = font['A']
print(f"Found '{glyph_A.name}' — width: {glyph_A.advanceWidth}")

# Find by name (returns None if not found — safer for scripting):
glyph_g = font.findName("g")
if glyph_g:
    print(f"Lowercase g: {glyph_g.advanceWidth} units wide")

# Find by unicode codepoint:
glyph_euro = font.findUnicode(0x20AC)   # €
if glyph_euro:
    print(f"Euro glyph: '{glyph_euro.name}'")

# Iterate every glyph:
empty_glyphs = []
for g in font.glyphs:
    if not g.hasBody:
        empty_glyphs.append(g.name)
print(f"Empty glyphs: {empty_glyphs}")

# ============================================================
# 4. Navigating the hierarchy: glyph → layer → shape → node
# ============================================================

# This is the most important pattern to understand.
# Everything lives inside everything else.

glyph   = font['H']
layer   = glyph.layers[0]          # first master layer
print(f"Layer '{layer.name}' has {len(layer.shapes)} shapes")

for shape in layer.shapes:
    for contour in shape.contours:
        print(f"  Contour: {len(contour.nodes)} nodes, "
              f"{'closed' if contour.closed else 'open'}")
        for node in contour.nodes:
            print(f"    ({node.x:.0f}, {node.y:.0f})  type={node.type}")

# ============================================================
# 5. Working with font-level guidelines
# ============================================================

from fontlab import flGuideLine

# Add a horizontal guideline at y=700 (e.g. for cap height):
gl = flGuideLine(0.0, QPointF(0, 700))
font.addGuideline(gl)

# List all font-level guidelines:
for guide in font.guidelines:
    print(f"Guide at angle={guide.angle}  pos={guide.centerPoint}")

# ============================================================
# 6. Masters in a variable font
# ============================================================

print(f"Masters: {font.masters}")
print(f"Active master: {font.master}")

# Switch to a different master:
if len(font.masters) > 1:
    font.setMaster(font.masters[1], notify=True)

# Read the design-space location of the active master:
loc = font.location()
print(f"Current location: {loc}")

# ============================================================
# 7. Editing font metadata
# ============================================================

info = font.info
print(f"Designer: {info.openTypeNameDesigner}")

# Write metadata — these end up in the font's name tables:
info.copyright              = "Copyright 2026 My Foundry"
info.openTypeOS2WeightClass = 400     # Regular weight
info.openTypeNameDesigner   = "Jane Smith"

# Font-level metrics (affects line spacing and hinting zones):
font.xHeight_value   = 500
font.capsHeight_value = 700
font.ascender_value  = 800
font.descender_value = -200

# ============================================================
# 8. Kerning
# ============================================================

master_name = font.masters[0]
pairs       = font.kerning(master_name)

# Print the first 5 kern pairs:
for (g1, g2), val in list(pairs.items())[:5]:
    print(f"  {g1} / {g2}  =  {val}")

# ============================================================
# 9. Saving
# ============================================================

# Save to the same location the font was opened from:
# font.save()

# Save to a new path:
# font.saveAs("/path/to/MyFont_v2.vfc")

    Current wrapper and naming helpers

    flPackage.hasInstaceFor(fg_font) is the registered spelling, including the missing "n" in "Instance"; hasInstanceFor is not an alias. clearActiveGlyphs() clears the package's active-glyph collection. checkVariableName(name) returns the native checked variable-name string. guidelinesHost is a read-only GuidelinesHostIntf interface value when exposed by the build; it does not imply that GuidelinesHostIntf is a constructible module class.
