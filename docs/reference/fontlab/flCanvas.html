    fontlab.flCanvas

    flCanvas

    A canvas is one editor window in FontLab — a glyph editor, a metrics window, or a text window. When you're drawing nodes in a glyph editor, you're looking at a canvas. flCanvas gives you scripting access to that window: its zoom level, what's selected, what's visible, and the coordinate mapping between the screen and your font data.

    You get the active canvas from the workspace:

    ws     = flWorkspace.instance()
canvas = ws.getActiveCanvas()

    Two coordinate systems — and why they matter

    This is the most important conceptual thing to understand about flCanvas. There are two coordinate systems in play whenever a glyph is on screen:

    • Glyph (font unit) coordinates — the "real" coordinates stored in your font. A node at x=250, y=700 is at those coordinates in font units, regardless of how zoomed in you are.
    • Canvas (screen pixel) coordinates — where that node actually appears on screen, in pixels, taking zoom and scroll position into account.

    When you're writing code that interacts with the visual display — checking what's under the mouse, doing hit testing, or snapping to canvas positions — you need to be able to move between these two systems. flCanvas provides the conversion methods:

    • glyphToCanvas(point) — takes a point in font units, returns where it appears on screen (in canvas pixels).
    • canvasToGlyph(point) — takes a screen pixel position, returns the corresponding font unit coordinate.

    Example: if a node is at glyph position (250, 700), and you're zoomed to 200%, glyphToCanvas might return something like (480, 300) in screen pixels. canvasToGlyph does the reverse — if the mouse is at screen pixel (480, 300), canvasToGlyph tells you the glyph coordinate underneath it.

    This matters for: - Hit testing — "did the user click near this node?" - Snap-to-point — "snap this to the nearest canvas grid point" - Custom drawing — drawing overlays or decorations that need to match glyph positions on screen

    Common Scripting Patterns

    from PythonQt.QtCore import QPointF
from fontlab import flWorkspace

ws     = flWorkspace.instance()
canvas = ws.getActiveCanvas()
if canvas is None:
    raise RuntimeError("Open a glyph window first.")

# Check zoom level
print("Current zoom:", canvas.scale())   # e.g. 2.0 for 200%

# Convert: glyph coords → screen position
import fontlab as fl
node_pos_in_font = QPointF(250, 700)
screen_pos = canvas.mapToViewport(node_pos_in_font)

# Convert: mouse position → glyph coords
mouse_screen = canvas.mousePosition()
mouse_glyph  = canvas.mapFromViewport(mouse_screen)

# Get selected nodes
nodes = canvas.selectedNodes()
for ni in nodes:
    print(ni)

# Force a full redraw
canvas.refresh()

# Deselect everything
canvas.unselectAll()

# Ensure a specific glyph bounding box is visible
# canvas.ensureVisible(some_rect)

    Tutorial

    from PythonQt.QtCore import QPointF, QRectF
import fontlab as fl
from fontlab import flWorkspace, flCanvas

# ============================================================
# 1. Get the active canvas
# ============================================================
# Always check that a canvas is open before proceeding.
# Scripts that assume a canvas is open will crash otherwise.

ws     = flWorkspace.instance()
canvas = ws.getActiveCanvas()

if canvas is None:
    print("No glyph window is open. Please open a glyph to edit.")
    raise SystemExit

print("Got canvas:", canvas)
print("Is active:", canvas.isActiveCanvas())
print("Has focus:", canvas.isFocusedCanvas())

# ============================================================
# 2. Zoom level
# ============================================================
# scale() returns a float: 1.0 = 100%, 2.0 = 200%, etc.

current_zoom = canvas.scale()
print(f"\nCurrent zoom: {current_zoom * 100:.0f}%")

# Zoom to 400% centered on the origin
# canvas.zoomTo(QPointF(0, 0), 4.0, fl.ViewPointAlignment.Center)

# ============================================================
# 3. Coordinate mapping — the most important canvas skill
# ============================================================
# These two systems are always in play:
#   - Glyph (font unit) coords: stored in the font, e.g. x=250, y=700
#   - Canvas (screen pixel) coords: where that point appears on screen

# A specific point in glyph/font units:
glyph_pt = QPointF(250, 700)

# Where does it appear on screen right now?
# mapToViewport takes a canvas-space point and returns a screen pixel point.
# (For glyph coords, the canvas transform includes zoom + pan.)
screen_pt = canvas.mapToViewportF(glyph_pt)
print(f"\nGlyph point {glyph_pt} appears on screen at {screen_pt}")

# And the reverse: what glyph coords is this screen position?
back = canvas.mapFromViewport(screen_pt)
print(f"Screen point {screen_pt} maps back to glyph {back}")

# scaled() tells you how many screen pixels = 1 font unit at current zoom:
pixels_per_unit = canvas.scaled(1.0)
print(f"At current zoom: 1 font unit = {pixels_per_unit:.2f} screen pixels")

# ============================================================
# 4. Selection — reading what the user has selected
# ============================================================
# selectedNodes() gives you canvas-level proxies (flNodeInfo)
# for each selected node.

selected = canvas.selectedNodes()
print(f"\nSelected nodes: {len(selected)}")

for ni in selected:
    # Each flNodeInfo knows where the node is on-screen
    print(f"  Node proxy: {ni}")

# Check if there's anything selected at all:
if canvas.haveSelectedNodes():
    print("Nodes are selected.")
else:
    print("No nodes selected.")

# Deselect everything:
canvas.unselectAll()
print("Deselected all.")

# ============================================================
# 5. Mouse position
# ============================================================
# mousePosition() returns canvas (screen pixel) coordinates.
# Use mapFromViewport to get the glyph-unit position under the cursor.

mouse_canvas = canvas.mousePosition()
mouse_glyph  = canvas.mapFromViewport(mouse_canvas)
print(f"\nMouse: screen={mouse_canvas}, glyph coords={mouse_glyph}")

# ============================================================
# 6. Built-in edit operations
# ============================================================
# These are equivalent to menu commands — they operate on
# whatever is currently selected in the canvas.

# Example: select all nodes first (requires glyph to be open)
# canvas.selectAll()

# Then apply an operation:
# canvas.operationReverseContours()   # reverse contour direction
# canvas.operationSimplify()          # remove redundant nodes
# canvas.operationToBeziers()         # convert to cubic beziers
# canvas.operationFlipHorizontal()    # mirror left/right

# ============================================================
# 7. Forcing a redraw
# ============================================================
# After making edits with other API calls, tell the canvas to
# refresh so the user sees the updated state.

canvas.refresh()       # standard full-canvas redraw
# canvas.refreshAll()  # heavier: clears all render caches too

# ============================================================
# 8. Highlight a region
# ============================================================
# Useful for drawing attention to a specific area — e.g.
# after finding a problem spot in the glyph.

problem_area = QRectF(200, 600, 100, 150)  # x, y, w, h in glyph units
canvas.highlight(problem_area)

# Remove the highlight when done:
# canvas.resetHighlight()

print("\nCanvas tutorial complete.")

    Python canvas painters

    appendPythonPainter(callback[, order]) -> int registers an overlay and returns a cleanup token. callback(painter, canvas) receives a borrowed QPainter whose transform has been reset for viewport coordinates. The default order is flCanvas.UnderOwner (0); flCanvas.OverOwner (1) draws above the owner. removePythonPainter(token) -> bool removes a callback from the same canvas and requests repainting.

    import fontlab as fl

canvas = fl.flWorkspace.instance().getActiveCanvas()
if canvas is not None:
    def overlay(painter, callback_canvas):
        painter.drawText(12, 24, "Python overlay")

    painter_token = canvas.appendPythonPainter(overlay, fl.flCanvas.OverOwner)
    # Keep canvas and painter_token while the overlay is needed.
    # Later, during cleanup:
    canvas.removePythonPainter(painter_token)

    Register and remove hooks on the GUI thread. Keep the token for cleanup; do not retain the borrowed painter beyond its callback or assume its wrapper remains valid. The native hook saves and restores painter state and guards against recursive painting. Exceptions are reported through Python's error output.
