    fontlab.Info

    Info

    Font Info data

    Complete font metadata.

    What is Info?

    Info is the metadata wrapper for all the descriptive information about your font that gets embedded in the file: the family name, style name, designer's name, copyright notice, license, all the OpenType metric values, PostScript hinting parameters, and much more.

    It follows the UFO (Unified Font Object) specification for attribute names, which means the property names like openTypeNameDesigner, openTypeOS2WeightClass, and postscriptFontName correspond directly to documented UFO 3 attributes. If you know UFO, you already know this interface.

    Access Info through package.info on an flPackage wrapper:

    package = fl.flPackage(fl.CurrentFont())
info = package.info
print(info.familyName)
info.copyright = "© 2026 My Foundry"

    All properties read/write the font's metadata storage directly. There is no need to call a save method — changes take effect immediately in the in-memory font.

    Basic Font Identification

    These are the most important fields for most type designers.

    Name Type Description Access
    familyName string The primary family name shown in application font menus (e.g. "Helvetica", "Times New Roman"). All styles in the family should share this name. read/write
    styleName string The style name within the family (e.g. "Regular", "Bold Italic", "Condensed Light"). read/write
    styleMapFamilyName string The "linked family" name used for bold/italic style mapping in older applications. Applications that only understand the 4-style model (Regular/Bold/Italic/BoldItalic) use this to group styles. read/write
    styleMapStyleName string The style position within the linked family group. Must be one of exactly four values: "regular", "italic", "bold", or "bold italic". read/write
    copyright string The full copyright statement embedded in the font file (e.g. "Copyright 2026 My Foundry. All rights reserved."). read/write
    trademark string The trademark statement, if any. read/write
    note string Arbitrary free-text note about the font. Not shown to end users; used for internal documentation. read/write
    unitsPerEm int/float Units per em — the scale of the design grid. read/write
    descender int/float The descender value for this font's default UPM-relative metrics. read/write
    ascender int/float The ascender value. read/write
    xHeight int/float The x-height value. read/write
    capHeight int/float The cap height value. read/write
    italicAngle int/float The italic angle in degrees, measured counter-clockwise from vertical. 0 for upright fonts; typically -12 to -15 for italic. read/write
    versionMajor int The major version number of the font (e.g. the 1 in version 1.012). read/write
    versionMinor int The minor version number. read/write
    year int Year of creation. Deprecated in UFO 3 in favour of openTypeHeadCreated, but still supported. read/write
    panose string Legacy PANOSE classification — 10 space-separated numbers. Most modern workflows ignore PANOSE, but it is required for some font delivery platforms. read/write

    OpenType hhea Table

    The hhea (horizontal header) table is used by older applications for line spacing. Values are in design units.

    Name Type Description Access
    openTypeHheaAscender int The ascender value written to hhea. May differ from the design ascender. read/write
    openTypeHheaDescender int The descender (negative) written to hhea. read/write
    openTypeHheaLineGap int Extra vertical space added between lines for hhea-based layout. read/write
    openTypeHheaCaretSlopeRise int For italic fonts: the rise component of the caret slope vector. read/write
    openTypeHheaCaretSlopeRun int For italic fonts: the run component of the caret slope vector. read/write
    openTypeHheaCaretOffset int Offset for the text insertion caret in italic fonts. read/write

    OpenType OS/2 Table

    The OS/2 table carries the most commonly queried font metadata, including the weight class (100–900) that determines how a font appears in application weight lists.

    Name Type Description Access
    openTypeOS2WeightClass int The weight class: 100=Thin, 200=ExtraLight, 300=Light, 400=Regular, 500=Medium, 600=SemiBold, 700=Bold, 800=ExtraBold, 900=Black. read/write
    openTypeOS2WidthClass int The width class: 1=UltraCondensed, 2=ExtraCondensed, 3=Condensed, 4=SemiCondensed, 5=Normal, 6=SemiExpanded, 7=Expanded, 8=ExtraExpanded, 9=UltraExpanded. read/write
    openTypeOS2WinAscent int The Windows-specific ascender (always positive). Controls the clipping boundary in Windows GDI rendering. read/write
    openTypeOS2WinDescent int The Windows-specific descender (always positive, despite being below baseline). read/write
    openTypeOS2TypoAscender int The typographic ascender (for cross-platform line spacing). read/write
    openTypeOS2TypoDescender int The typographic descender (negative). read/write
    openTypeOS2TypoLineGap int The typographic line gap. read/write
    openTypeOS2VendorID string Four-character vendor/foundry code registered with Microsoft (e.g. "ADBO" for Adobe). read/write
    openTypeOS2Panose list OS/2 Panose classification: a list of 10 integers. read/write
    openTypeOS2FamilyClass list Font family class: [classID, subclassID] from the OS/2 specification. read/write
    openTypeOS2UnicodeRanges list List of bit indices indicating which Unicode ranges the font supports. read/write
    openTypeOS2CodePageRanges list List of bit indices indicating which Windows code pages the font supports. read/write
    openTypeOS2StrikeoutSize int Thickness of the strikethrough stroke in design units. read/write
    openTypeOS2StrikeoutPosition int Vertical position of the strikethrough (from baseline). read/write
    openTypeOS2Type list Embedding permission flags (fsType). read/write
    openTypeOS2Selection list Style selection flags (fsSelection) — bold, italic, regular, etc. Do not include bits 0, 5, or 6. read/write
    openTypeOS2SubscriptXSize int Suggested subscript glyph width. read/write
    openTypeOS2SubscriptYSize int Suggested subscript glyph height. read/write
    openTypeOS2SubscriptXOffset int Suggested subscript horizontal offset. read/write
    openTypeOS2SubscriptYOffset int Suggested subscript vertical offset (downward). read/write
    openTypeOS2SuperscriptXSize int Suggested superscript width. read/write
    openTypeOS2SuperscriptYSize int Suggested superscript height. read/write
    openTypeOS2SuperscriptXOffset int Suggested superscript horizontal offset. read/write
    openTypeOS2SuperscriptYOffset int Suggested superscript vertical offset (upward). read/write

    OpenType Name Table

    The name table stores human-readable strings that applications display when users browse or install fonts.

    Name Type Description Access
    openTypeNameDesigner string Name ID 9 — the name of the type designer. read/write
    openTypeNameDesignerURL string Name ID 12 — the designer's website URL. read/write
    openTypeNameManufacturer string Name ID 8 — the name of the foundry/manufacturer. read/write
    openTypeNameManufacturerURL string Name ID 11 — the foundry's website URL. read/write
    openTypeNameLicense string Name ID 13 — the full text of the font's license agreement. read/write
    openTypeNameLicenseURL string Name ID 14 — URL where the license can be found. read/write
    openTypeNameVersion string Name ID 5 — the version string as it appears in font info (e.g. "Version 1.012"). read/write
    openTypeNameUniqueID string Name ID 3 — a string uniquely identifying this version of this font. read/write
    openTypeNameDescription string Name ID 10 — a description of the typeface's design, history, or usage. read/write
    openTypeNamePreferredFamilyName string Name ID 16 — the preferred family name shown in design-aware applications. Use this to set the full family name for variable fonts or large families. read/write
    openTypeNamePreferredSubfamilyName string Name ID 17 — the preferred subfamily name. read/write
    openTypeNameCompatibleFullName string Name ID 18 — the Macintosh-compatible full name for QuickDraw compatibility. read/write
    openTypeNameSampleText string Name ID 19 — sample text shown in font preview panels. read/write
    openTypeNameWWSFamilyName string Name ID 21 — the Weight-Width-Slope (WWS) family name. read/write
    openTypeNameWWSSubfamilyName string Name ID 22 — the WWS subfamily name. read/write
    openTypeNameRecords list Localised name records — a list of [platformID, encodingID, languageID, nameID, string] tuples for multi-language fonts. read/write

    Name Type Description Access
    openTypeGaspRangeRecords list gasp range records, sorted ascending by rangeMaxPPEM. Each record is [rangeMaxPPEM, rangeGaspBehavior]. Controls whether grid-fitting and/or symmetric smoothing is used at different display sizes. read/write

    PostScript / CFF

    These are the PostScript-specific font-level metadata fields.

    Name Type Description Access
    postscriptFontName string The PostScript font name (the FontName in a Type 1 dictionary). Should be short, no spaces, no special characters. read/write
    postscriptFullName string The PostScript full name (FullName in the font dictionary). read/write
    postscriptWeightName string The PostScript weight string (e.g. "Regular", "Bold"). read/write
    postscriptUniqueID int PostScript unique ID number. read/write
    postscriptIsFixedPitch bool True if the font is monospaced — all glyphs have the same advance width. read/write
    postscriptForceBold bool The ForceBold flag in the CFF Private dictionary. read/write
    postscriptDefaultWidthX int/float Default advance width for glyphs. Used to save space in the CFF data when most glyphs share one width. read/write
    postscriptNominalWidthX int/float The "nominal" width deviation stored in CFF. read/write
    postscriptBlueValues list Up to 14 blue zone values (in pairs). These define the horizontal bands used for PS alignment-zone hinting. Example: [0, 10, 490, 500, 690, 700] for baseline+overshoot, x-height+overshoot, capHeight+overshoot. read/write
    postscriptOtherBlues list Up to 10 "other blues" values — the downward-facing alignment zones (for the descender area). read/write
    postscriptFamilyBlues list Family-level blue values, shared across all styles to ensure consistent zone snapping. read/write
    postscriptFamilyOtherBlues list Family-level other blues. read/write
    postscriptStemSnapH list Up to 12 representative horizontal stem widths. These are the widths of horizontal strokes in the font (e.g. the thickness of the crossbar on 'H'). read/write
    postscriptStemSnapV list Up to 12 representative vertical stem widths — the thickness of vertical strokes (e.g. the left stroke of 'H'). read/write
    postscriptBlueFuzz int/float How much to extend each blue zone. read/write
    postscriptBlueScale float PPEM at which overshoots stop being suppressed. read/write
    postscriptBlueShift int/float Minimum overshoot for suppression. read/write
    postscriptUnderlinePosition int/float Vertical position of the underline (from baseline, negative values go below). read/write
    postscriptUnderlineThickness int/float Thickness of the underline stroke. read/write
    postscriptDefaultCharacter string Name of the glyph used as the default character in Windows PFM metrics. read/write
    postscriptWindowsCharacterSet int Windows character set identifier for this font. read/write

    Macintosh Legacy

    Name Type Description Access
    macintoshFONDFamilyID int Macintosh FOND resource family ID. Needed only for very old Mac compatibility. read/write
    macintoshFONDName string Macintosh FOND resource font name. read/write

    Tutorial

    import fontlab as fl

font = fl.CurrentFont()
info = font.info   # FontInfo object — direct read/write access

# ============================================================
# 1. Read the most important identification fields.
# ============================================================

print("--- Font Identification ---")
print(f"Family:    {info.familyName}")
print(f"Style:     {info.styleName}")
print(f"Designer:  {info.openTypeNameDesigner}")
print(f"Copyright: {info.copyright}")
print(f"Version:   {info.versionMajor}.{info.versionMinor:03d}")
print(f"UPM:       {info.unitsPerEm}")

# ============================================================
# 2. Check the key vertical metrics.
# ============================================================

print("\n--- Vertical Metrics ---")
print(f"Ascender:   {info.ascender}")
print(f"Descender:  {info.descender}")
print(f"x-Height:   {info.xHeight}")
print(f"Cap Height: {info.capHeight}")
print(f"Italic Angle: {info.italicAngle}°")

# ============================================================
# 3. Check OS/2 classification fields.
# These determine how the font appears in weight/width menus.
# ============================================================

print("\n--- OS/2 Classification ---")
print(f"Weight class: {info.openTypeOS2WeightClass}  "
      f"(400=Regular, 700=Bold)")
print(f"Width class:  {info.openTypeOS2WidthClass}  "
      f"(5=Normal, 3=Condensed)")
print(f"Vendor ID:    '{info.openTypeOS2VendorID}'")

# ============================================================
# 4. Update copyright and license fields.
# This is one of the most common pre-export scripts.
# ============================================================

info.copyright = "Copyright 2026 My Foundry. All rights reserved."
info.openTypeNameDesigner    = "Jane Smith"
info.openTypeNameDesignerURL = "https://myfoundry.example.com"
info.openTypeNameManufacturer    = "My Foundry"
info.openTypeNameManufacturerURL = "https://myfoundry.example.com"
info.openTypeNameLicense    = (
    "This Font Software is licensed under the SIL Open Font License, "
    "Version 1.1. This license is available with a FAQ at: "
    "https://scripts.sil.org/OFL"
)
info.openTypeNameLicenseURL = "https://scripts.sil.org/OFL"
info.versionMajor = 1
info.versionMinor = 0
print("\nIdentification fields updated.")

# ============================================================
# 5. Read PostScript hinting metadata.
# These are the font-level values (separate from per-master
# flHintingParameters, which override these).
# ============================================================

print("\n--- PostScript Blues ---")
print(f"BlueValues: {info.postscriptBlueValues}")
print(f"OtherBlues: {info.postscriptOtherBlues}")
print(f"StemSnapH:  {info.postscriptStemSnapH}")
print(f"StemSnapV:  {info.postscriptStemSnapV}")

# ============================================================
# 6. Set the PostScript font name (required for OTF export).
# The PS name should have no spaces and no special characters.
# ============================================================

family = (info.familyName or "MyFont").replace(" ", "")
style  = (info.styleName  or "Regular").replace(" ", "")
info.postscriptFontName = f"{family}-{style}"
info.postscriptFullName = f"{info.familyName} {info.styleName}"
print(f"\nPS name set to: '{info.postscriptFontName}'")

    Common Scripting Patterns

    Quick metadata update before export

    import fontlab as fl

package = fl.flPackage(fl.CurrentFont())
info = package.info
info.copyright               = "© 2026 My Foundry."
info.openTypeNameDesigner    = "Jane Smith"
info.openTypeOS2VendorID     = "MYFO"
info.versionMajor            = 1
info.versionMinor            = 0
print("Metadata updated.")

    Print all PostScript blue values

    import fontlab as fl

package = fl.flPackage(fl.CurrentFont())
info = package.info
print(f"BlueValues:  {info.postscriptBlueValues}")
print(f"OtherBlues:  {info.postscriptOtherBlues}")
print(f"StemSnapH:   {info.postscriptStemSnapH}")
print(f"StemSnapV:   {info.postscriptStemSnapV}")
print(f"BlueScale:   {info.postscriptBlueScale}")
print(f"BlueShift:   {info.postscriptBlueShift}")

    Auto-generate PostScript names from family/style

    import fontlab as fl

font = fl.CurrentFont()
info = font.info

family = (info.familyName or "Untitled").replace(" ", "")
style  = (info.styleName  or "Regular").replace(" ", "")

info.postscriptFontName = f"{family}-{style}"
info.postscriptFullName = f"{info.familyName} {info.styleName}"
print(f"PS name: {info.postscriptFontName}")

    Verify all name-table fields are filled

    import fontlab as fl

package = fl.flPackage(fl.CurrentFont())
info = package.info
required = {
    "familyName":               info.familyName,
    "styleName":                info.styleName,
    "copyright":                info.copyright,
    "openTypeNameDesigner":     info.openTypeNameDesigner,
    "openTypeNameManufacturer": info.openTypeNameManufacturer,
    "openTypeNameLicense":      info.openTypeNameLicense,
    "postscriptFontName":       info.postscriptFontName,
    "openTypeOS2VendorID":      info.openTypeOS2VendorID,
}

print("--- Required fields check ---")
all_ok = True
for field, value in required.items():
    status = "✓" if value else "✗ MISSING"
    if not value:
        all_ok = False
    print(f"  {status}  {field}: '{value or ''}'")

if all_ok:
    print("\nAll required fields are filled.")
else:
    print("\nSome fields are missing — fill them before export.")

    Custom Unicode–name mapping and Other settings

    Property Type Access Meaning
    nametablePath str or None read/write Font-wide custom .nam path; assignment reloads the mapping. Empty/None selects the standard mapping.
    otherData dict read/write Snapshot of additional settings; assign a dictionary to patch selected entries.

    font.info.nametablePath reads or sets the font-wide .nam path shown in Font Info > Other. Assignment reloads the mapping immediately. Use "" or None to restore the standard mapping. Relative paths resolve from the font's folder; an unreadable file retains its configured path and uses standard mapping with a warning.

    font.info.otherData returns a dictionary snapshot of the current master's Other settings (including loop resolution and TrueType hinting controls), plus the font-wide nametablePath. Assign a dictionary to patch selected entries; mutating the returned snapshot alone does not update the font. PANOSE retains its existing font.info.panose / font.info.openTypeOS2Panose access.

    font.info.nametablePath = "names/custom.nam"
font.info.otherData = {"nametablePath": "names/custom.nam"}
font.info.otherData = {"nametablePath": None}  # standard mapping

    MCP uses set_font_info with {"font_info": {"other_data": {"nametablePath": "names/custom.nam"}}}. otherData is also accepted. get_font_info returns the configured value in other_data.nametablePath. This setting applies to every master; do not put it inside masters[].
