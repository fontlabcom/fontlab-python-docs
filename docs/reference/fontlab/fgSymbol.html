    fontlab.fgSymbol

    fgSymbol

    A single character identity record.

    What is fgSymbol?

    Every slot in a text string that FontLab renders in the metrics view is represented by an fgSymbol. Think of it as a small ticket that says "show me the glyph for the letter 'A' (Unicode 0x0041)." It also carries a glyph ID (the slot index in the font), a layer name (which master to use), and can hold arbitrary custom data.

    You will encounter fgSymbol objects mainly when working with fgSymbolList (a complete string of characters) or through flGlyphInfo.symbol (the symbol for a rendered glyph slot in the metrics view).

    Tutorial

    import fontlab as fl
from fontlab import fgSymbol

# ============================================================
# Create a symbol for the letter 'A' and inspect it.
# You normally get symbols from an fgSymbolList rather than
# creating them manually, but this shows the structure.
# ============================================================

sym = fgSymbol()
sym.id = 0x0041   # set to Unicode code point for 'A'

print(f"Unicode: {hex(sym.unicode)}")   # 0x41
print(f"Name:    '{sym.name}'")
print(f"Empty:   {sym.empty}")
print(f"Has unicode: {sym.hasUnicode}")

# ============================================================
# Attach custom data to a symbol.
# DataCode is just an integer key you choose — use any number.
# This is useful for tagging symbols during batch processing.
# ============================================================

sym.setData(1, "needs-review")
print(f"Has data at code 1: {sym.containsData(1)}")
print(f"Data: {sym.data(1)}")

# Clear the data when done:
sym.clearData(1)
print(f"After clear: {sym.containsData(1)}")

# ============================================================
# Resolve a symbol within a specific font.
# Call computeID() to find out which glyph slot 'A' occupies
# in the currently open font.
# ============================================================

font = fl.CurrentFont()
sym2 = fgSymbol()
sym2.id = 0x0041   # 'A'
found = sym2.computeID(font)
if found:
    print(f"'A' is at glyph index {sym2.glyphIndex} in font '{font.info.familyName}'")
else:
    print("Glyph 'A' not found in current font")

# ============================================================
# Check if two symbols refer to the same character.
# Useful when searching a symbol list.
# ============================================================

sym3 = fgSymbol()
sym3.id = 0x0042   # 'B'

print(f"sym2 == sym2: {sym2.compare(sym2)}")  # True
print(f"sym2 == sym3: {sym2.compare(sym3)}")  # False

    Common Scripting Patterns

    Choose a master or location for each symbol

    Master selection uses the master/layer name; fgSymbol has no master property. Repeated occurrences of the same glyph can carry different overrides.

    import fontlab as fl

light = fl.fgSymbol("a")
light.setLayerOverride("Light")
instance = fl.fgSymbol("a")
instance.setLocation(fl.flLocation({"wt": 450}))
symbols = fl.fgSymbolList([light, instance])

print(symbols[0].layerName)       # Light
print(symbols[1].hasLocation)     # True
print(symbols[1].location["wt"])  # 450

# List access returns a copy: assign the edited symbol back.
symbol = symbols[0]
symbol.setLayerOverride("Bold")
symbols.set(0, symbol)

symbol = symbols[1]
symbol.clearPresentationOverride()
symbols.set(1, symbol)

    location also returns a copy. To change coordinates, construct a new flLocation from a dictionary and pass it to symbol.setLocation(). Coordinates use the font's design space; axis short names such as "wt" are supported.

    flGlyphInfo.symbol is a copy as well. To change a displayed occurrence, use flGlyphInfo.setActiveLayer(layer), setLocation(location), or clearPresentationOverride() on the flGlyphInfo itself.

    Check if a symbol is a line break

    from fontlab import fgSymbol
sym = fgSymbol()
sym.id = 0x000D   # carriage return
print("Is CR:", sym.cr)

    Transfer a symbol between fonts (clear old IDs, resolve in new font)

    from fontlab import fgSymbol
sym = fgSymbol()
sym.id = 0x0041

font_a = fl.CurrentFont()
sym.computeID(font_a)   # resolve in font A

# Now move to font B:
sym.clearID()           # discard font-A-specific IDs
font_b = ...            # another open font
sym.computeID(font_b)   # resolve in font B
