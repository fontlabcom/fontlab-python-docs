    fontlab.flWorkspace

    flWorkspace

    flWorkspace is the FontLab application itself — represented as a Python object. It knows which fonts you have open, which glyph window is in front, what tool is active, and what zoom level you're looking at. When you want to do anything at the application level — loop over all open fonts, switch to a different window, change the active tool, or trigger an export — flWorkspace is where you start.

    You always get to it the same way:

    ws = flWorkspace.instance()

    That gives you the running FontLab application. There's only ever one.

    As a type designer writing scripts, you'll use flWorkspace for:

    • Finding open fonts — ws.packages() gives you a list of every font currently open.
    • Knowing which font is in focus — ws.currentPackage is the font whose window is active.
    • Accessing the active glyph window — ws.getActiveCanvas() gives you the editor window you're looking at.
    • Switching tools — ws.setToolEditor(), ws.setToolPen(), etc.
    • Exporting fonts — ws.exportCurrentFont() or ws.exportFont(pkg, options).
    • Batch scripts — loop over ws.packages() to process every open font.

    Getting the Instance

    from fontlab import flWorkspace
ws = flWorkspace.instance()

    Common Scripting Patterns

    from fontlab import flWorkspace

ws = flWorkspace.instance()

# Get the active font
font = ws.currentPackage

# Get the active glyph editor window
canvas = ws.getActiveCanvas()

# Loop over all open fonts
for pkg in ws.packages():
    print(pkg.info.familyName)

# Suppress screen flicker during a batch edit
ws.blockUpdate(5000)   # suppress for up to 5 seconds
# ... make many edits ...
ws.unblockUpdate()     # release immediately when done

# After batch edits, ensure screen is refreshed
ws.updateActiveViewport()

# Switch to the node editor tool when your script finishes
ws.setToolEditor()

    Tutorial: Looping Over All Open Fonts

    This pattern is the foundation of most batch-processing scripts.

    from PythonQt.QtGui import QTransform
import fontlab as fl
from fontlab import flWorkspace, flModel

ws = flWorkspace.instance()

# ============================================================
# 1. Which font is active right now?
# ============================================================

active_font = ws.currentPackage
if active_font:
    print(f"Active font: {active_font.info.familyName}")
else:
    print("No font is currently active.")

# ============================================================
# 2. Loop over every open font
# ============================================================

all_fonts = ws.packages()
print(f"\n{len(all_fonts)} font(s) open:\n")

for pkg in all_fonts:
    info = pkg.info
    # info.familyName and info.styleName give you the font's
    # family and style names as they appear in Font Info
    print(f"  {info.familyName}  {info.styleName}")

# ============================================================
# 3. Do something to every glyph in every open font
# ============================================================
# Example: print the glyph count for each open font.

for pkg in ws.packages():
    glyph_count = len(pkg.glyphs)
    name = pkg.info.familyName or "(unnamed)"
    print(f"  {name}: {glyph_count} glyphs")

# ============================================================
# 4. Batch edit with update suppression
# ============================================================
# When making many edits across many glyphs, block screen
# updates first to avoid flickering and speed things up.

changed_ids = set()

ws.blockUpdate(10000)   # suppress updates for up to 10 seconds

try:
    for pkg in ws.packages():
        for glyph in pkg.glyphs:
            # Example: shift every glyph's first layer right by 10 units
            if not glyph.layers:
                continue
            layer = glyph.layers[0]
            for shape in layer.shapes:
                shape.transform = QTransform().translate(10, 0)
            changed_ids.add(glyph.id)
finally:
    # Always unblock, even if the script errors partway through
    ws.unblockUpdate()

# Notify FontLab about all the changes at once
flModel.notifyGlyphsChanged(changed_ids)
ws.updateActiveViewport()

# ============================================================
# 5. Export every open font to a folder
# ============================================================
# Note: exportCurrentFont() uses the settings from Font Info.
# For custom export options, use exportFont(pkg, ExportControl).

# for pkg in ws.packages():
#     ws.currentPackage = pkg   # make it active
#     ws.exportCurrentFont()

# ============================================================
# 6. Access the active canvas and glyph
# ============================================================

canvas = ws.getActiveCanvas()
if canvas:
    print(f"\nCanvas is active: {canvas.isActiveCanvas()}")
    # The currentGlyph property tells you which glyph is in
    # the editor right now
    glyph_info = ws.currentGlyph
    if glyph_info:
        print(f"Currently editing: {glyph_info.name}")
else:
    print("\nNo canvas is open — open a glyph window to get the canvas.")

# ============================================================
# 7. Switching tools at the end of a script
# ============================================================
# Good practice: leave the user in a sensible tool state
# after your script finishes. The node editor is usually
# the right choice.

ws.setToolEditor()
print("\nScript complete. Switched to Node Editor tool.")

    Registering a Python tool

    registerPythonTool(name, icon, object) -> int adds a tool to the palette/menu and returns a cleanup token. icon must be a PythonQt QIcon or None. unregisterPythonTool(token) -> bool removes the registered tool and deactivates it if necessary. Run both operations on the GUI thread.

    The callback object can implement activate() and deactivate() with no arguments; mouse callbacks mousePressed(event, canvas), mouseMoved(event, canvas), mouseReleased(event, canvas) and mouseDoubleClicked(event, canvas); key callbacks keyPressed(event, canvas) and keyReleased(event, canvas); and paint(painter, canvas). Event callbacks receive borrowed Qt QMouseEvent/QKeyEvent wrappers, not flMouseEvent. Return a truthy value to consume an event, or false/None to allow normal processing. Painter coordinates are viewport coordinates.

    import fontlab as fl

class ExampleTool:
    def mousePressed(self, event, canvas):
        print(event.pos())
        return False

workspace = fl.flWorkspace.instance()
tool_token = workspace.registerPythonTool("Example Python tool", None, ExampleTool())
# Retain tool_token; later, during plugin/script cleanup:
workspace.unregisterPythonTool(tool_token)

    The registry keeps the callback object alive while registered. Do not retain borrowed event/painter wrappers beyond their callbacks. Keep cleanup tokens and unregister before unloading a plugin. Callback errors are printed to Python output. The registration does not itself select the tool.
