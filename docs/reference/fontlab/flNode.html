    fontlab.flNode

    flNode

    What Is a Node?

    If you've ever edited a glyph in FontLab's glyph editor, you've clicked on nodes. A node is a single point on a Bézier curve contour — it's the fundamental building block of every letter shape you draw. When you look at a capital "S" in the glyph editor, you're looking at a collection of nodes connected by curve segments, and it's those nodes that define where the path goes and how it bends.

    There are two fundamental kinds of nodes: on-curve nodes and off-curve nodes (also called handles or control points). On-curve nodes lie directly on the path — they're the filled squares or circles you see in the editor. Off-curve nodes (the hollow circles connected by dotted lines) sit off to the side of the curve and act like magnets, pulling the curve toward them without the path actually passing through them. In PostScript (Type 1 / OpenType CFF) fonts, every curve segment between two on-curve nodes has exactly two off-curve control points — this is the classic cubic Bézier. In TrueType fonts, each curve segment can be described with a single off-curve point between two on-curve anchors.

    On-curve nodes can also be smooth or corner nodes. A smooth node keeps its two neighboring handles in a straight line through it, producing a fluid, tangent-continuous transition between the incoming and outgoing curves. A corner node lets the handles point in any direction, creating a sharp angle or cusp. In FontLab, smooth nodes are shown as circles and corner nodes as squares. When you're scripting, the smooth property tells you which kind you have, and setting it to True or False instantly changes the node's behavior.

    Tutorial

    This tutorial walks through the most common node operations you'll use in scripts: accessing nodes from a glyph, reading their properties, navigating between them, creating new nodes by hand, and performing transforms. Each section builds on the previous one.

    import fontlab as fl
from fontlab import flNode

# ── Step 1: Get a contour to work with ──────────────────────────────────────
# We'll use the first shape on the first layer of the glyph "A".
# In practice you'd pick the glyph and layer relevant to your task.
font    = fl.CurrentFont()
glyph   = font['A']
layer   = glyph.layers[0]
shape   = layer.shapes[0]
contour = shape.contours[0]

    # ── Step 2: Inspect every node in the contour ────────────────────────────────
# node.type tells you 'on' or 'off'; node.smooth tells you if it's smooth.
# This is the first script most designers write when exploring an outline.
for node in contour.nodes():
    print(f"  ({node.x:.1f}, {node.y:.1f})  type={node.type}  smooth={node.smooth}")

    # ── Step 3: Create nodes manually and build a triangle ──────────────────────
# nodeType='on' means the path passes through the point.
# nodeType='off' means it's a Bézier handle — the path is pulled toward it.
n1 = flNode(0,   0,   nodeType='on')   # bottom-left corner
n2 = flNode(200, 0,   nodeType='on')   # bottom-right corner
n3 = flNode(100, 300, nodeType='on')   # apex

# Adding them to a new closed contour:
tri = fl.flContour()
tri.closed = True
for n in [n1, n2, n3]:
    tri.add(n)
shape.addContour(tri)

    # ── Step 4: Navigate between nodes ──────────────────────────────────────────
# nextNode() with no argument returns the very next node (on OR off curve).
# nextNode('on') skips handles and jumps to the next on-curve anchor.
node = contour.nodes()[0]
nxt  = node.nextNode()          # next node of any type
prv  = node.prevNode()          # previous node of any type

# Find the nearest off-curve handle that follows this node:
next_off = node.nextNode(nodeType='off')
if next_off and not next_off.isNull:
    print(f"  outgoing handle: ({next_off.x}, {next_off.y})")

    # ── Step 5: Change node properties ───────────────────────────────────────────
# Toggle a node between corner and smooth — the handles will snap to collinear.
node = contour.nodes()[0]
node.smooth = True     # make this a smooth (tangent-continuous) point
node.smooth = False    # revert to a corner

# Move a node:
node.x += 10           # nudge right by 10 units
node.moveBy(0, -5)     # nudge down by 5 units (no rounding)
node.moveBy(5, 0, round=True)   # move right 5 units, snap to integer

# Select it so you can see the change in the editor:
node.selected = True

    # ── Step 6: Convert curve segments to/from lines ────────────────────────────
# convertToLine() removes handles from the incoming segment, making it straight.
# convertToCurve() adds handles to prepare a node for curve editing.
for node in contour.nodes():
    if node.isOn():               # only work on on-curve nodes
        if node.isCurve():
            node.convertToLine()  # straighten this segment

fl.Update()                       # refresh the display

    # ── Step 7: Check and use node geometry queries ──────────────────────────────
# isExtreme() identifies nodes at horizontal or vertical extrema.
# These are the nodes that should exist for proper PostScript hinting.
for node in contour.nodes():
    if node.isOn() and node.isExtreme(x=False):  # vertical extreme
        print(f"  Vertical extreme at ({node.x:.1f}, {node.y:.1f})")

fl.Update()

    Common Scripting Patterns

    These ready-to-use patterns cover the tasks designers most often automate with node-level scripting.

    Move all smooth nodes up by 10 units

    Useful for nudging the smooth transition points in a design across all glyphs, for example when adjusting x-height in a batch operation.

    import fontlab as fl

font = fl.CurrentFont()
for glyph in font.glyphs:
    for layer in glyph.layers:
        for shape in layer.shapes:
            for contour in shape.contours:
                for node in contour.nodes():
                    if node.isOn() and node.smooth:
                        node.moveBy(0, 10)
fl.Update()

    Select all extremum nodes (vertical and horizontal)

    Select the topmost, bottommost, leftmost, and rightmost nodes on every contour. FontLab highlights these after running extremes(), but this script lets you query and select them manually.

    import fontlab as fl

font  = fl.CurrentFont()
glyph = font['O']
layer = glyph.layers[0]

for shape in layer.shapes:
    for contour in shape.contours:
        for node in contour.nodes():
            if node.isOn():
                if node.isExtreme(x=True) or node.isExtreme(x=False):
                    node.selected = True

fl.Update()

    Convert all curve nodes to line nodes in a glyph

    Strips all Bézier handles from a glyph, reducing every curve to a straight line. Handy for creating a simplified or geometric version of a design.

    import fontlab as fl

font  = fl.CurrentFont()
glyph = font['S']
layer = glyph.layers[0]

for shape in layer.shapes:
    for contour in shape.contours:
        for node in contour.nodes():
            if node.isOn() and node.isCurve():
                node.convertToLine()

fl.Update()

    Round all node coordinates to integers

    Ensures every node in the current glyph has integer coordinates — a required step before manual hinting in many workflows.

    import fontlab as fl

font  = fl.CurrentFont()
glyph = font['g']
layer = glyph.layers[0]

for shape in layer.shapes:
    for contour in shape.contours:
        for node in contour.nodes():
            node.round()   # snaps x and y to nearest integer

fl.Update()

    Find nodes that are nearly smooth but flagged as corners

    Sometimes imported outlines have handles that are almost collinear but the smooth flag isn't set. This script finds and fixes them.

    import fontlab as fl

font  = fl.CurrentFont()
glyph = font['n']
layer = glyph.layers[0]
fixed = 0

for shape in layer.shapes:
    for contour in shape.contours:
        for node in contour.nodes():
            if node.isOn() and not node.smooth:
                if node.canBeSmooth():
                    node.smooth = True
                    fixed += 1

print(f"Fixed {fixed} near-smooth nodes")
fl.Update()
