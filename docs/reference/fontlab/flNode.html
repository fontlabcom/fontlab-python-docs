    fontlab.flNode

    flNode

    flNode representation

    Constructors: flNode() flNode(Node) - make clone flNode(QPointF position[, string nodeType="on"[, int nodeKind=None]]) flNode(double x, double y[, string nodeType="on"[, int nodeKind=None]])

    Native bases: object

    Supplemental documentation: A contour node with native x, y, type and smooth members. Its type distinguishes on-curve points from off-curve control points. Read or assign x and y on the original native object.
