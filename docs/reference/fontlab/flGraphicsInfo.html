    fontlab.flGraphicsInfo

    flGraphicsInfo

    Canvas-transform-aware info object.

    What is flGraphicsInfo?

    flGraphicsInfo extends flSearchInfo with the one thing that makes canvas rendering possible: the transformation matrix (transform) that maps from glyph-space coordinates (font units) to canvas-space coordinates (screen pixels at the current zoom level).

    Once you have an flGraphicsInfo, you can convert any glyph-space point to its screen position by applying the transform. Conversely, you can map screen coordinates back to glyph coordinates using the inverse transform. Every shape, contour, and node info object inherits from flGraphicsInfo, which is why all of them can answer "where on screen am I?".

    Most scripting that works with canvas positions will receive flGraphicsInfo (or one of its subclasses like flShapeInfo, flContourInfo, or flNodeInfo) back from a query method rather than constructing one directly.

    Tutorial

    The transform property is the bridge between the mathematical world of font units and the visual world of the screen. Here is how to use it to map points between the two coordinate systems.

    from PythonQt.QtCore import QPointF
import fontlab as fl

# ============================================================
# Get the canvas transform for a specific shape on screen.
# flShapeInfo inherits from flGraphicsInfo, so every shape
# info object has a .transform property.
# ============================================================

ws     = fl.flWorkspace.instance()
canvas = ws.getActiveCanvas()
if canvas is None:
    print("Open a glyph window first.")
    raise SystemExit

gi = canvas.activeGlyphInfo()
if gi is None:
    print("No active glyph.")
    raise SystemExit

# Get shape infos through a broad contour query:
all_contours = gi.getNearbyContours(QPointF(0, 0), 99999, "")

if all_contours:
    ci = all_contours[0]
    si = ci.shapeInfo   # flShapeInfo, which has transform

    # The transform maps glyph units → canvas pixels:
    tx = si.transform

    # Map a glyph-space point to canvas space:
    glyph_pt = QPointF(100, 500)        # 100 units right, 500 units up
    canvas_pt = tx.map(glyph_pt)           # apply the transform
    print(f"Glyph ({glyph_pt.x():.0f}, {glyph_pt.y():.0f}) "
          f"→ Canvas ({canvas_pt.x():.1f}, {canvas_pt.y():.1f})")

    # Map back from canvas → glyph space using the inverse:
    inverse_tx = tx.inverted()[0]          # inverted() returns (QTransform, bool_ok)
    back = inverse_tx.map(canvas_pt)
    print(f"Canvas ({canvas_pt.x():.1f}, {canvas_pt.y():.1f}) "
          f"→ Glyph ({back.x():.1f}, {back.y():.1f})")

    Common Scripting Patterns

    Get the canvas zoom level from a shape's transform
    from PythonQt.QtCore import QPointF
import fontlab as fl
import math

ws  = fl.flWorkspace.instance()
gi  = ws.getActiveCanvas().activeGlyphInfo() if ws.getActiveCanvas() else None
if gi:
    contours = gi.getNearbyContours(QPointF(0, 0), 99999, "")
    if contours:
        tx = contours[0].shapeInfo.transform
        # The scale factor is the length of the first column vector:
        zoom = math.hypot(tx.m11(), tx.m21())
        print(f"Current canvas zoom: {zoom:.3f}× (1.0 = 100%)")
