    fontlab.flShapeData

    flShapeData

    The Shared Drawing Record.

    What Is flShapeData?

    Every flShape has an flShapeData sitting behind it. While flShape is the editing shell you interact with in the layer — it carries the transform, selection state, and lock flags — flShapeData is where the actual drawing lives: the contours, the include list for composites, and the parametric builder reference.

    Most of the time you work with flShape directly and never think about flShapeData. But it becomes important in two situations:

    Components. When a glyph reuses artwork from another glyph (for example, a shared accent in an accented character), multiple flShape objects across different glyphs can point to the same flShapeData. The referenceCount property tells you how many shapes are currently sharing that data. If referenceCount > 1, you are looking at a shared component — editing the contours inside the flShapeData directly would affect every shape that references it, which is usually not what you want. In that case, work through the flShape and let FontLab manage the copy-on-write logic.

    Low-level contour assembly. Sometimes you want to build up contours and structure directly at the data level — for example, when reading from an external source and constructing a shape programmatically. flShapeData lets you manage contours, includes, and ordering without going through the full shape layer machinery.

    Why Does referenceCount Matter?

    Imagine you have a font with 200 accented characters, all sharing the same acute accent element. That one acute lives in one flShapeData object, referenced by 200 different flShape objects (one per glyph-layer). The referenceCount would be 200. If you need to modify only one glyph's acute, you must first make a private copy of the data. FontLab normally handles this automatically when you edit through the UI, but in scripts that manipulate flShapeData directly, you are responsible for avoiding accidental shared edits.

    Tutorial

    This tutorial shows how to read shape data from an existing glyph, build new shape data from scratch, and work with composite and component shapes.

    import fontlab as fl
from fontlab import flShapeData, flContour, flNode

font  = fl.CurrentFont()

# ----------------------------------------------------------------
# Part 1: Reading shape data from a glyph
# ----------------------------------------------------------------
# Access the shape data via any shape in the glyph's layer.
glyph = font['O']
layer = glyph.layers[0]
shape = layer.shapes[0]

sd = shape.shapeData

# Print the type so we know what kind of shape we're dealing with.
print("ShapeType:", sd.shapeType)       # Contour | Composite | Image | Component
print("Is composite:", sd.isComposite)
print("Is component:", sd.isComponent)

# The reference count tells us how many shapes share this data.
# If it's greater than 1, this is shared component data.
print("Reference count:", sd.referenceCount)
if sd.referenceCount > 1:
    print("  WARNING: Shared data — edits here affect all references!")

# ----------------------------------------------------------------
# Part 2: Inspecting contours through shape data
# ----------------------------------------------------------------
# You can access contours either through flShape.contours or flShapeData.contours.
# The shape data path is useful when you need to work below the shape level.
for contour in sd.contours:
    nodes = contour.nodes()
    print(f"  Contour: {len(nodes)} nodes, closed={contour.closed}")

# The segments property gives you a flat list of all Bézier segments
# across all contours — handy for geometric analysis.
for seg in sd.segments:
    print(f"  Segment: p0={seg.p0}  p3={seg.p3}")

# ----------------------------------------------------------------
# Part 3: Building shape data from scratch
# ----------------------------------------------------------------
# Create a fresh shape data object and add contours to it manually.
new_sd = flShapeData()

# Build a simple square contour and add it.
c = flContour()
c.closed = True
for x, y in [(0, 0), (100, 0), (100, 100), (0, 100)]:
    c.append(flNode(x, y, nodeType='on'))
new_sd.addContour(c)

# After adding contours, arrange them so outer contours precede inner ones.
# This is required for correct rendering in font engines.
reordered = new_sd.arrangeContours()
print("Contours reordered:", reordered)

# Attach a note for traceability — useful in batch-generation scripts.
new_sd.note = "Generated by script — square reference mark"
print("Note:", new_sd.note)

# ----------------------------------------------------------------
# Part 4: Composite shapes — inspecting and reordering children
# ----------------------------------------------------------------
# Find a composite shape in the font (if any) and inspect its children.
for gname in font.glyphsNames:
    g = font[gname]
    for lyr in g.layers:
        for sh in lyr.shapes:
            if sh.isComposite:
                sd2 = sh.shapeData
                children = sd2.includesList()
                print(f"\n{gname}: composite with {len(children)} children")
                for child in children:
                    print(f"  child shapeType={child.shapeType}")

                # Move the first child to the front of the rendering stack.
                if len(children) >= 2:
                    moved = sd2.sendToFront(children[0])
                    print("  Sent first child to front:", moved)
                break  # just show one composite for the tutorial

# ----------------------------------------------------------------
# Part 5: Component shapes — reading the source glyph
# ----------------------------------------------------------------
# Components reference artwork from another glyph.
# Find all components in the font and print where they come from.
glyph = font.get('agrave')
if glyph:
    for lyr in glyph.layers:
        for sh in lyr.shapes:
            if sh.isComponent:
                sd3 = sh.shapeData
                print(f"Component: from '{sd3.componentGlyph}' layer '{sd3.componentLayer}'")

# ----------------------------------------------------------------
# Part 6: Sorting and normalising contours
# ----------------------------------------------------------------
# Sorting is useful before comparing shapes for interpolation compatibility.
shape = layer.shapes[0]
sd = shape.shapeData
sd.sortContours(True)   # True = apply the sort for real
print("Contours sorted.")

fl.Update()

    Common Scripting Patterns

    Checking if it's safe to edit shape data directly

    sd = shape.shapeData
if sd.referenceCount > 1:
    print("Shared data — do not edit directly, work through flShape instead")
else:
    print("Private data — safe to edit directly")

    Adding a note to every shape in a glyph (for batch audit)

    glyph = font['A']
for layer in glyph.layers:
    for i, shape in enumerate(layer.shapes):
        shape.shapeData.note = f"shape_{i}_layer_{layer.name}"

    Getting all Bézier segments for geometric analysis

    all_segments = []
for shape in layer.shapes:
    if shape.simpleShape():
        all_segments.extend(shape.shapeData.segments)
print(f"Total segments in layer: {len(all_segments)}")

    Listing all component sources in a font

    for gname in font.glyphsNames:
    g = font[gname]
    for layer in g.layers:
        for shape in layer.shapes:
            if shape.isComponent:
                src = shape.shapeData.componentGlyph
                print(f"{gname} → component of '{src}'")

    Fixing contour winding order on all glyphs

    for gname in font.glyphsNames:
    g = font[gname]
    for layer in g.layers:
        for shape in layer.shapes:
            if shape.simpleShape():
                changed = shape.shapeData.arrangeContours()
                if changed:
                    print(f"  Fixed winding in {gname}/{layer.name}")
fl.Update()

    Reordering composite children (bring the widest one to front)

    for shape in layer.shapes:
    if shape.isComposite:
        sd = shape.shapeData
        children = sd.includesList()
        widest = max(children, key=lambda s: s.boundingBox.width())
        sd.sendToFront(widest)
fl.Update()

    # assignContours returns a mapping from old IDs to new contours,
# which lets you remap any anchors or other references.
new_contours = [build_contour()]    # your contour-building function
id_map = shape.shapeData.assignContours(new_contours)
print("ID remapping:", id_map)
