    fontlab.flItems

    flItems

    flItems is FontLab's application-wide event megaphone. Whenever anything happens in the application — a glyph is activated, a selection changes, a font is opened, a canvas gets focus — flItems broadcasts a signal so that all the UI panels, inspectors, and displays can react and update themselves.

    As a type designer writing scripts, you use flItems to tell FontLab that your script has changed something, so the displays refresh correctly. Without these calls, the screen won't update — you might edit 50 glyphs and see no change until you click somewhere.

    You access it as a class with static methods — no instance needed:

    from fontlab import flItems

# Tell FontLab a glyph was updated (triggers display refresh)
flItems.notifyGlyphUpdated(package_id, glyph_id)

# Request that a specific UI dialog opens
flItems.requestFontInfoDlg()

    notify vs request — what's the difference?

    These two prefixes mean very different things:

    • notify* — "I just changed something. Please update your displays." You call these after making a change. They're announcements: "glyph data changed", "the active layer changed", "preferences changed". FontLab's UI listens for these signals and refreshes whatever needs refreshing.

    • request* — "Please do this for me." You call these to ask FontLab to perform an action — open a dialog, activate a glyph, load a font, run an operation. The difference from calling the operation directly is that request* goes through the normal UI pipeline, complete with undo recording, validation, and UI state management.

    A useful way to think about it: notify* is telling the application about the past ("this already happened"), while request* is asking it to do something in the future ("please do this now").

    Static initialization and instance access

    items = flItems.instance()

    Although flItems has an instance() method, almost all its methods are static — you can call them directly on the class without getting an instance first. Call flItems.init() once during plugin startup to ensure the event system is properly wired up.

    Common Scripting Patterns

    from fontlab import flItems

# ---- After editing a single glyph ----
font  = fl.CurrentFont()
glyph = font['A']
# ... make changes to glyph data ...
flItems.notifyGlyphUpdated(font.id, glyph.id)

# ---- After editing many glyphs ----
changed = set()
for name in glyph_names:
    g = font[name]
    # ... edit g ...
    changed.add(g.id)
flItems.notifyGlyphsUpdated(font.id, changed)

# ---- Record an undo step ----
# Call notifyChangesApplied before making changes so the undo
# system captures the before-state:
flItems.notifyChangesApplied("My script operation", glyph)

# ---- Progress bar for long-running scripts ----
flItems.requestProgressShow(True)
flItems.requestProgressRange(len(glyphs))
for i, g in enumerate(glyphs):
    flItems.requestProgressMessage(f"Processing {g.name}...")
    flItems.requestProgressValue(i)
    # ... process g ...
flItems.requestProgressShow(False)

# ---- Open Font Info dialog ----
flItems.requestFontInfoDlg()

    Tutorial

    from PythonQt.QtGui import QTransform
import fontlab as fl
from fontlab import flItems

# ============================================================
# Understanding flItems: the "please update" and "please do"
# system. Two categories of calls:
#
#   notify* = "I changed data, please refresh displays"
#   request* = "please run this operation for me"
# ============================================================

font = fl.CurrentFont()

# ============================================================
# 1. The most important pattern: notify after editing
# ============================================================
# Whenever a script edits a glyph directly (moving nodes,
# changing contours, adjusting metrics), FontLab's UI
# won't know until you fire a notification.

glyph = font['A']

# Make a change (example: shift the first shape)
layer = glyph.layers[0]
if layer.shapes:
    shape = layer.shapes[0]
    shape.transform = QTransform().translate(10, 0)

# NOW tell FontLab what happened:
flItems.notifyGlyphUpdated(font.id, glyph.id)
# The font window, glyph window, and all panels will refresh.

# ============================================================
# 2. Batch editing — use the batch notification for speed
# ============================================================
# Calling notifyGlyphUpdated inside a loop is wasteful.
# Collect changed glyph IDs and notify all at once.

changed_ids = set()

for name in ['A', 'B', 'C', 'D', 'E']:
    g = font[name]
    if not g or not g.layers:
        continue
    layer = g.layers[0]
    for shape in layer.shapes:
        shape.transform(QTransform().translate(5, 0))
    changed_ids.add(g.id)

# One notification for all the changed glyphs:
flItems.notifyGlyphsUpdated(font.id, changed_ids)
print(f"Notified {len(changed_ids)} glyph(s) updated.")

# ============================================================
# 3. Making edits undoable
# ============================================================
# notifyChangesApplied tells the undo system to record an
# undo step. Pass a label (shown in Edit > Undo) and the
# object(s) that changed. Call BEFORE making the change
# so the undo system captures the before-state.

glyph_b = font['B']
flItems.notifyChangesApplied("Nudge B", glyph_b)
# ... now make the change ...
if glyph_b.layers and glyph_b.layers[0].shapes:
    glyph_b.layers[0].shapes[0].transform(QTransform().translate(20, 0))
flItems.notifyGlyphUpdated(font.id, glyph_b.id)
# The user can now Cmd+Z to undo "Nudge B".

# ============================================================
# 4. Showing a progress bar for long operations
# ============================================================
# For scripts that process many glyphs, show a progress bar
# so the user knows the script is running.

all_glyphs = list(font.glyphs)

flItems.requestProgressShow(True)
flItems.requestProgressRange(len(all_glyphs))

for i, g in enumerate(all_glyphs):
    flItems.requestProgressMessage(f"Processing {g.name} ({i+1}/{len(all_glyphs)})...")
    flItems.requestProgressValue(i + 1)
    # ... do something with g ...

# Always hide the bar when done
flItems.requestProgressShow(False)
print("Done — progress bar hidden.")

# ============================================================
# 5. Opening dialogs via request*
# ============================================================
# These go through the normal UI pipeline, triggering
# the same behavior as clicking the menu item.

# Open the Font Info dialog:
# flItems.requestFontInfoDlg()

# Activate the node editor tool:
# flItems.requestActivateNodesTool()

# Ask FontLab to open a glyph by its IDs:
# flItems.requestGlyphActivate(font.id, font['A'].id)

# ============================================================
# 6. After changing preferences, notify the system
# ============================================================
# If your script changes flPreferences values, call this
# so all panels and displays refresh to use the new settings.

# from fontlab import flPreferences
# prefs = flPreferences.instance()
# prefs.snapToGuidelines = True
# flItems.notifyPreferencesChanged()

# ============================================================
# 7. The workspace property
# ============================================================

ws = flItems.instance().workspace
print("Workspace from flItems:", ws)
