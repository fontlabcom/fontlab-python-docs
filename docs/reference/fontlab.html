    Overview

    Python interface for FontLab data objects

    Architecture

    The FontLab Python API is a C++/Python binding layer:

    The class articles document registered names, member kinds, calling conventions and property access. Some APIs depend on build flags. The separate fontgate module and inherited PythonQt/Qt APIs are outside this inventory.

    CurrentFont() returns fgFont, and CurrentGlyph() returns fgGlyph. Use fl.flPackage(fg_font) or fl.flGlyph(fg_glyph) when calling the model APIs described by the fl* guides. Constructing a wrapper from an existing model object does not imply an independent geometry copy; use the appropriate clone() operation when a separate object is needed.

    Type Conventions

    Throughout the documentation, types use these conventions:

    Type Meaning
    str Python string (C++ QString)
    float Python float (C++ double)
    int Python integer
    bool Python bool
    QPointF Qt 2D point; use PythonQt.QtCore.QPointF unless the specific overload documents tuple conversion
    QRectF Qt rectangle; use PythonQt.QtCore.QRectF unless the specific overload documents tuple conversion
    QTransform 3×3 matrix — passed as a QTransform-like object
    QColor Qt color; use PythonQt.QtGui.QColor unless the specific overload documents tuple conversion
    list(T) Python list of type T
    T/None Returns T or Python None

    Calling conventions and inherited members

    Registered methods take positional arguments unless their class article explicitly lists keyword support. Optional values shown as name=default in signatures do not by themselves imply keyword support. flNode documents its keyword-capable methods. Value-wrapper constructors document their own field-keyword initialization.

    Inherited registrations are documented in the base class article; each class article names its binding base where applicable. C++ inheritance alone does not guarantee that a base member is exposed in Python. Binding annotations record declared signatures and can be incomplete; implementation notes in the class articles qualify known differences.

    High-level FontLab editing API. flGlyph contains drawing layers, flLayer contains shapes, and flContour contains nodes. CurrentFont() and CurrentGlyph() access the active editing context.

    Source: FontLab Proteus API documentation
