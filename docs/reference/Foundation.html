    Foundation

    Foundation

    The Foundation module glyport gives Glyphs scripts: Cocoa value types plus Qt-backed classes, menus, drawing and events. It never imports PyObjC.

    Re-exported from glyport: GSInspectorView, GSMouseOverButton, GSPaletteView, GSSteppingTextField, NSAffineTransform, NSAffineTransformStruct, NSArray, NSArrayController, NSAttributedString, NSBezierPath, NSBox, NSButton, NSColor, NSComboBox, NSControl, NSCursor, NSDate, NSDictionary, NSEdgeInsetsMake, NSEvent, NSFont, NSFrameRect, NSGraphicsContext, NSGridView, NSHeight, NSImage, NSImageView, NSIndexPath, NSIndexSet, NSInsetRect, NSLog, NSMakePoint, NSMakeRange, NSMakeRect, NSMakeSize, NSMatrix, NSMaxX, NSMaxY, NSMenu, NSMenuItem, NSMidX, NSMidY, NSMinX, NSMinY, NSMutableArray, NSMutableOrderedSet, NSMutableParagraphStyle, NSMutableSet, NSNotification, NSNumberFormatter, NSObject, NSPanel, NSPathControl, NSPoint, NSPopUpButton, NSPredicate, NSProgressIndicator, NSRange, NSRect, NSRectFill, NSRunLoop, NSScrollView, NSSearchField, NSSecureTextField, NSSegmentedControl, NSSize, NSSlider, NSSplitView, NSStackView, NSString, NSSwitch, NSTabView, NSTabViewItem, NSTableCellView, NSTableColumn, NSTableView, NSTextField, NSTextView, NSURL, NSUnionRect, NSUserDefaultsController, NSValue, NSView, NSVisualEffectView, NSWidth, NSWindow.

    Names not listed here raise UnsupportedCapability at runtime.

    Documentation is derived from captured and enriched Echopy source. Native objects are supplied by FontLab.
