    Compound Glyph Info without losing record state

    The numerical ordinary-artifact results below identify their retained predecessor checkpoint. The current manager/profile guide documents the H source changes. Earlier source assumptions are corrected below; original preimages remain in verification evidence. Old receipts do not qualify the new ordinary tuple or native behavior.

    Use Glyphs.glyphInfoForName to inspect a multi-code spelling such as uni00660069. Read the resulting name, stored production and components together; the final spelling alone does not describe how the records were resolved. A whole-name database hit can preempt composition, and a suffix can introduce a nested compound. These metadata queries do not implement glyph editing/export.

    The current private candidate follows the retained Glyphs 4 compound contract. Source and genuine Glyport archives pass their recorded checks; the new matching Echopy/ordinary consumer cohort is still being qualified. Native FontLab/Glyphs workflows, custom/local managers and complete proprietary recipes remain open.

    Prepare owned offline records

    For the controls below, first run the owned session setup. It exports the actual classes through ExecutionContext/FontLabSession, using empty packages/defaults and inert host objects outside FontLab. It restores the maintained dataset afterward. A normal script gets Glyphs from its own Glyport execution context; this fixture is for reproducible offline checks.

    def two_letters():
    return [
        {"name": name, "unicode": code, "category": "Letter", "script": "latin"}
        for name, code in [("A", "0041"), ("B", "0042")]
    ]

    Read the compound and its fields

    Composition clears the compound's primary encoding while retaining component order. This owned two-Letter case has the retained Ligature classification.

    with owned_glyphs(two_letters()) as exports:
    info = exports.Glyphs.glyphInfoForName("uni00410042")
    assert type(info) is exports.GSGlyphInfo
    assert (info.name, info.productionName, info.unicode) == ("A_B", "A_B", None)
    assert (info.category, info.subCategory, info.script, info.case) == (
        "Letter", "Ligature", "latin", 0)
    assert [part.name for part in info.components] == ["A", "B"]

    Observe the first fill and later component fill

    The first ordinary name lookup fills a known nil production. A later exact B lookup is visible through the shared B component, while the compound keeps the production it already stored. This does not make every metadata field a live view.

    with owned_glyphs(two_letters()) as exports:
    app = exports.Glyphs
    a, b = app.glyphInfoForUnicode("0041"), app.glyphInfoForUnicode("0042")
    info = app.glyphInfoForName("uni00410042")
    assert (a.productionName, b.productionName) == ("A", None)
    assert info.components[1].productionName is None
    app.glyphInfoForName("B")
    assert info.components[1].productionName == "B"
    assert info.productionName == "A_B"

    Keep duplicate positions and shallow component references

    The list getter returns a separate container. Repeated positions can still refer to the same component object; clearing your list does not clear the compound.

    with owned_glyphs(two_letters()) as exports:
    info = exports.Glyphs.glyphInfoForName("uni00410041")
    assert len(info.components) == 2
    assert info.components[0] is info.components[1]
    copied_list = info.components
    copied_list.clear()
    assert [part.name for part in info.components] == ["A", "A"]

    Distinguish raw production from helper output

    The raw field can differ from the helper's effective component output. Mixed Unicode rebuilding uses the saved raw record list, including an explicit value.

    rows = two_letters()
rows[0]["production"] = "uniFFFF"
with owned_glyphs(rows) as exports:
    raw = exports.Glyphs.glyphInfoForUnicode("0041")
    info = exports.Glyphs.glyphInfoForName("uni00410042")
    assert raw.productionName == "uniFFFF"
    assert info.productionName == "uniFFFF0042"

    Traverse a suffix wrapper once

    A global suffix may wrap one unsuffixed compound. Preserve that nested record instead of assuming every result exposes a flat A/B list.

    with owned_glyphs(two_letters()) as exports:
    info = exports.Glyphs.glyphInfoForName("uni00410042.ss01")
    assert (info.name, info.productionName) == ("A_B.ss01", "A_B.ss01")
    assert len(info.components) == 1 and info.components[0].name == "A_B"
    assert [part.name for part in info.components[0].components] == ["A", "B"]

    Let an exact whole-name record win

    Do not infer a compound from spelling alone. An exact represented name wins before decoding and does not fill the unused A/B records. The public row does not establish a physical recipe, so reading components refuses explicitly instead of inventing an empty list.

    rows = two_letters() + [{
    "name": "uni00410042", "production": "OwnedWinner", "category": "Mark",
}]
with owned_glyphs(rows) as exports:
    app = exports.Glyphs
    info = app.glyphInfoForName("uni00410042")
    assert (info.productionName, info.category) == ("OwnedWinner", "Mark")
    from fontlab_glyport.errors import UnsupportedCapability
    try:
        _ = info.components
    except UnsupportedCapability as error:
        assert error.capability == "GSGlyphInfo.components.source"
    else:
        raise AssertionError("This public row does not establish a physical recipe")
    assert app.glyphInfoForUnicode("0041").productionName is None
    assert app.glyphInfoForUnicode("0042").productionName is None

    Keep positional records separate from production inputs

    Actual Arabic alternates can replace final components. Their raw nil productions remain nil; the compound's production still uses the earlier saved inputs.

    rows = [
    {"name": "beh-ar", "unicode": "0628", "production": "uni0628", "script": "arabic", "category": "Letter"},
    {"name": "alef-ar", "unicode": "0627", "production": "uni0627", "script": "arabic", "category": "Letter"},
    {"name": "beh-ar.init", "unicodeLegacy": "FE91", "script": "arabic", "category": "Letter"},
    {"name": "alef-ar.fina", "unicodeLegacy": "FE8E", "script": "arabic", "category": "Letter"},
]
with owned_glyphs(rows) as exports:
    info = exports.Glyphs.glyphInfoForName("uni06280627")
    assert [part.name for part in info.components] == ["beh-ar.init", "alef-ar.fina"]
    assert [part.productionName for part in info.components] == [None, None]
    assert info.productionName == "uni06280627"

    Keep metadata reads separate from writes

    The returned stored production is read-only. Use the separate glyph/export contracts for editing; assigning to this snapshot must refuse without a change.

    from fontlab_glyport.errors import UnsupportedCapability
with owned_glyphs(two_letters()) as exports:
    info = exports.Glyphs.glyphInfoForName("uni00410042")
    try:
        info.productionName = "changed"
    except UnsupportedCapability as error:
        assert error.capability == "GSGlyphInfo.productionName"
    else:
        raise AssertionError("Stored metadata must remain read-only")
    assert info.productionName == "A_B"

    Account for the retained long-production rebuild

    At 62 UTF16 units, a successful raw Unicode rebuild replaces the assembled production, including its earlier global suffix. Name and production can differ.

    rows = two_letters()
rows[0]["production"], rows[1]["production"] = "P" * 56, "Q"
with owned_glyphs(rows) as exports:
    info = exports.Glyphs.glyphInfoForName("uni00410042.alt")
    assert info.name == "A_B.alt"
    assert info.productionName == "uni00410042"
